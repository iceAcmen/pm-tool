# D4 · 阶段1 饱和终检（第4轮·轻量）diverger-4

> 任务：通读三轮池（round1 146 / round2 109 / round3 75 单元+91 变体，合计 346），判定「方向空间里是否还存在池子完全没触及的新类别」。纪律：同一方向的另一变体/另一极端/另一 UI 细节不算新方向；诚实比多产重要。
> 方法：先按标题地图建立覆盖清单，再对 ≥5 个强制角度逐一反查（关键词 + 上下文核对），命中即判定被覆盖，不硬凑。

## 总判定

**发现 2 条池内未触及的方向，其中 1 条明确成立、1 条为弱候选；其余强制角度全部被池内某类想法覆盖或仅为变体。** 三轮在「pm-tool ↔ dsh 宿主如何接、数据/证据怎么闭环、自主还是审批、独立还是融合、沉默还是提醒、怎么分发/退役」这条主轴上已高度饱和；未触及的都在主轴之外的价值主体/纵向层级上。

---

## 新方向 1（明确成立）：人的保护面 / 可持续层——「项目服务人」而非「人服务项目」

### 为什么三轮 346 条都没覆盖
- 池里所有「少打扰」机制——D1-R2-13 建议配额与沉默期、D5-R2-10 建议合并/草稿 TTL/提醒聚合、D2-R2-17 自适应沉默、D1-24/D4-26 极致沉默、S9 仪式节流——**目标都是「让建议更好被采纳、把项目推得更顺」**，降噪是为了推进，不是为了让人停下来。
- D3-25 个人负载视图、D4-R2-04 组合取舍是「项目争用/资源聚焦」视角，度量的是任务量分配，不是人的状态。
- 关键词全池反查：倦怠 0、休息 0、留白 0、burnout 0、情绪仅 1 处（且是描述宿主弃用焦虑，非功能）、周末仅 1 处（手机看盘场景）、健康 50 处全部是「健康灯/health」而非 wellbeing。
- 池内价值主体从头到尾是「项目/任务」，没有任何一条把「保护执行的人」设为目标。

### 一句话机制
在推进侧（提醒/到期/催办/进度）之外，增设一条对称的「保护侧」：记录人的状态/能量/负荷上限，主动劝停、周末与夜间静默、把休息和留白当一等公民，项目让位于人。

### 最极端形态
产品默认替人踩刹车：检测到连续 N 个夜间/周末会话、单日在册任务超个人上限、或一周零休整时，系统不再催办，反而给出「今天到此为止」的收工提示并冻结当日新建议；休息/留白作为与 task 并列的一类实体被显式排进计划，项目进度曲线与可持续曲线并列展示，宁可项目慢也不让人过载。

### 与池内相邻想法的分界（避免被误判为变体）
- 区别于 D2-R2-17/D5-R2-10：那些是「减少噪音以提高采纳」，本方向是「主动停止推进以保护人」，价值主体相反。
- 区别于 D3-25 负载：那是项目间资源争用（理性分配），本方向是人的健康边界（保护主体）。
- 诚实边界：这条落在锁定问题框（R1–R5 全是项目/台账/宿主关系）的外侧，是否属于本产品方向空间需评审门裁定；它不需要 dsh 宿主能力也能成立，更像产品价值观分支而非融合方案。

## 新方向 2（弱候选，标注边界）：纵向层级缺口——项目之上的愿景层、项目之下的习惯层

### 为什么三轮没覆盖
- 七实体与全部想法都夹在「周 / 里程碑 / 交付物」中段：向上没有「项目为什么存在、北极星/年度目标」的活实体，向下没有「日常重复动作/习惯」层。
- D1-26「十年可读」是归档存档，不是活的目标层；D4-R2-04 的「战略权重」只是给项目打个标签，不是可分解、可追踪的上层目标；关键词反查：愿景 0、OKR 0、路线图 0、打卡 0、习惯仅出现在组织者清单措辞里，无对应功能。

### 一句话机制
在项目之上加一层可分解的长期目标（愿景/年度 OKR，向下拆成项目），在项目之下加一层日常重复动作（习惯/周期行为，向上汇入项目），工具从「单项目中段记录」变成「愿景—项目—习惯」纵向贯通。

### 最极端形态
一个北极星目标挂着多个项目，每个项目是它的阶段性分解；每天的习惯动作（练、写、读）自动计入相关项目的投入，年底把习惯曲线与项目达成并置，回答「我这一年到底往愿景走了多远」。

### 诚实降级说明
这是弱候选：上层与 D4-R2-04 组合取舍、D1-R2-03 模板库相邻，下层与 S9 仪式卡、completion-history 按周聚合相邻，很可能被评审门判为现有机制的纵向延伸而非独立类别；且同样落在 R1–R5 框外。列出仅为不漏，不主张其为硬空白。

## 饱和结论
1. 主轴（融合深度、证据闭环、自主/审批、独立/吞并、沉默/提醒、规划智能、PMO 编排、商业分发、退出）三轮已饱和，未发现第三类立场。
2. 唯一明确的池外方向是**人的保护面/可持续层（新方向 1）**，但它在锁定问题框 R1–R5 之外，是否纳入由评审门决定。
3. 弱候选**纵向愿景/习惯层（新方向 2）**大概率是现有机制的纵向延伸，仅登记不主张。
4. 其余强制角度（非软件行业、五年后技术、故意失败、法务、终止管理、游戏化、多人协作、换载体、纯无 AI）均已被池内想法覆盖或只是变体，不另立方向。
