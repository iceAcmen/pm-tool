## 三、每页叙事模板（硬性）

每张效果图/每个交互必须能回答五问：
1. **什么时候用**：场景导语（自然中文，不用编号）。
2. **你点什么**：用户在 dsh 里做的一个具体动作（如「在对话里说：帮我把这段说明补到任务里」/「点开 AI副驾」）。
3. **系统替你做什么**：画面中模型/插件的动作与产出。
4. **你看到什么结果**：嵌入 dsh 壳里的具体界面变化（任务条目、卡片、队列、导出文件等）。
5. **和现在有何不同**：一行白话对比（如「以前要自己逐条补备注，现在说一句即可，改前可核对」）。

标题用自然中文功能名（如「早上打开，先看到要处理的」）；原编号只放标题括号小字（如「（K11）」）。

## 四、能力边界（设计严禁夸大，画面与文案双查）

- **K2**：只支持备注/证据链接类受限直写 + 关键变化展示确认 + 可撤销；**不能**展示自动改关键状态/负责人/排期。
- **K11**：只改善**打开后**的提醒整理与静音；**不承担**系统级常驻主动推送（H6 缺口，显著标注未实现）。
- **K18**：只读分发/受控单向动作，**不是**飞书/Jira 双向同步；目标平台标注「待确认」。
- **X6**：粗糙即时复盘草稿 → 证据不足留白 → 补材料/正式复盘会 → 定稿；业务完成状态不等复盘；无积分/连胜/徽章动效。
- **X7**：愿景/OKR 层与习惯层**两层都保留**，仅建议分期（愿景层先）；连续记录断签超窗重置、累计档案永久保留、2 天补记窗。
- **K12**：只增日志+可物理删除（删除权优先）+ N/M 采纳计数描述统计；样本不足不下结论；不做防篡改链/法律举证。
- **K1**：按需读取主路线（poll > 文件只读投影 > 全局轻量计数）；无常驻注入。
- **K9**：单向结存（会话→台账），非双向镜像；高置信自动挂可撤销、低置信人一键采纳。
- **K3**：只收会话内工作痕迹；公司系统动作仍人工粘贴。
- **K4**：观察模式先行、只记录浮出结果不落库；人逐条确认才进箱；预填标题/到期占位。
- **K6**：只列一致性+缺口（「未覆盖≠未完成」），不背书完成、不下完成裁决。
- **K13**：对话卡片=只读投影+单动作回写，旧卡片失效遮罩；真源在本地数据。
- **X5**：自述数字与可核验证据分栏，待核标注，导出默认排除待核；不承诺信用证明。
- **X2**：毕业=人工声明+洁净度勾选+回潮自动摘标；不做「N 周未打开即成功」。
- **X3**：死因双栏（个人可改进/外部原因），锚点缺失只存事实不开归因；中性归档。
- **K16**：通用 JSON+语义字典+结项一次性 PDF/A；只承诺留档可读，不承诺可复现/可再生成。
- 所有「条件性采纳/待验证」如实标注（如 K18 目标平台待用户举证、X6 依赖证据收集、X7 保留率待观察）。

1. 嵌入 dsh 三栏壳（左1 功能导航 / 左2 PM工作台 / 右主内容区），展示具体项目（G3验收项目）、任务、会话与生成结果；示例数据显式标注虚构。

3. 每页五问叙事完整；标题自然功能名，编号仅括号小字。
4. 浅深两态均为真设计（深色换底板/线/文字，非反色），token 沿用 §1.3。
5. 拒绝：暖黄/廉价大字数字卡/文字贴边/窄表单错位/无意义留白/廉价动画徽章堆砌。
6. 不夸大能力边界（§4 逐条核对）。
7. 交互真实（无僵尸按钮）：按钮有点击后的状态变化或明确说明；交互用确定性 HTML+少量 JS 实现。
8. 每个主场景页 = 1 个自包含 HTML（相对路径引用共享 css/js 可），配套 `_shots/` 截图：桌面浅、桌面深、移动端（390×844）至少各 1 张 + 关键交互态截图；每场景 1 份白话说明 md（五问叙事）。
9. 交付前用 shot.py 或等价工具渲染截图门禁；交付后跑 artifact-preview 自检。
