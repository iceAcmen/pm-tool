诚实清单：没做的、并入的、暂不建议的

能力边界与未实现项 · 全部 30 项一行定位；本页是设计附录，不是功能承诺。
示例数据 · 设计示意 含未实现项诚实标注

A当期主线（在推荐组合内，一行定位）

这些是本期真正落在推荐组合里的能力，各自一行白话定位。
按需读取K1
你问项目状态时才去读台账并注明依据，无常驻注入。
主路线是你开口才查；不常驻往你这边推内容。
窄集直写K2
只允许改备注、补挂证据链接；改前展示关键变化、可撤销。
不自动改任务状态、负责人或排期。
会话内证据K3
只把会话里的工作痕迹收成证据；公司系统动作仍人工粘贴。
自动收集面只覆盖会话内，不外扩。
承诺浮出K4
聊天里出现的承诺先观察记录，人逐条确认才进待办箱。
不宣称「录入趋零」，判断留在人手里。
交付前查缺口K6
只列一致性与材料缺口，「未覆盖≠未完成」，不替你验收。
不下完成裁决，不背书完成。
组合轻选K8
项目只给高/中/低三档权重，聚合进总览看板，不给保/缓/砍结论。
单人无分配对象，客观分配已删除。
单向结存K9
会话单向结存到台账；代挂建议人确认，不做扇出执行。
撤回常驻油门/规则刹车，只留只读适配点。
打开后整理K11
打开后把到期未达整理成队列，迟到标注、可静音；不主动推送。
只改善打开视图，H6 主动触达已剥离悬置。
回滚账本K12
AI 改动只增日志、可物理删除；N/M 只做描述统计。
样本小不下结论，不做防篡改链/法律举证。
对话卡片K13
只读投影 + 单动作回写；旧卡片失效置灰，真源在本地。
不设第二状态库，避免两边漂移。
档案契约K16
通用格式 + 字段字典 + 结项静态切片；只承诺留档可读。
不承诺可复现/可再生成，撤长期迁移器。
单向出站K18
一次性只读导出/受控单向发出；外部为唯一事实源，非双向同步。
撤持续状态页与实时移动页。
毕业声明X2
人工声明 + 洁净度勾选；回潮自动摘标。
不做「N 周未打开即成功」的自动判定。
失败中性归档X3
死因双栏（个人可改进/外部原因）；锚点缺失只存事实不归因。
库规模达标前仅记录，不强制。
述职素材库X5
数字与可核验证据分栏，待核标注，导出默认排除待核。
去「证据库」证明力，不对外背书。
即时复盘草稿X6
完成后先出粗糙草稿，补材料后定稿；完成≠定稿。
证据不足留白不编造；无积分/连胜/徽章。
愿景/OKR 层先做X7
单父归属 + 软关联行；AI 代起草人确认；习惯层分期待拍板。
两层都保留，仅建议分期，不伪造全勤曲线。

B未实现 / 明确不做（诚实标注）

这些要么当前做不到，要么明确决定不做，不画成已上线。
常驻主动推送H6 · 未实现
当前未实现
依赖宿主通知能力：临期/逾期/承诺到期主动推到桌面/手机，本期不承诺。
宿主当前无邮件/短信/系统推送渠道，错过不补发；工具自己也不引入常驻进程。
外部平台接入K18 · 待举证
目标平台待你举证
现在只做只读分发；接入团队现用平台（不预设）尚未确认。
团队事实源平台需你举证，未确认前不预设任何平台。
双向同步明确不做
不做
不做飞书/Jira/表格与本地台账的双向镜像同步。
单机单写者，双向镜像必然撞写，同步无意义且会崩。
自主缔约Y1a · 不做
不做
不让 AI 独立对外签约、承诺、自动报价、自主结算。
AI 不是民事主体，也没有持牌资金通道，法律主体与结算两层阻断。
认证/采购市场Y1b · 不做
不做
不进入等保/信创认证与政府采购体系，不宣称过认证。
个人无供应商资格、无系统可测、担不起组织级持续义务，三层错配。

C并入何处（合并方向归属，一行说明）

被撤并方向不直接消失，说明它的内容并进了哪里。
K5 会议流并入
合并归属
会前应读包并入 K1 按需读取（时间触发变体）；会后认领并入 K4 候选箱；分段录音转写仅作会议总结的输入方式。
剥完无独立机制，且宿主不是会议容器。
K8 项目组合并入
合并归属
聚合视图并入总览看板；客观分配删除（单人无分配对象），只留三档权重。
组合取舍只剩展示层，不独立成方向。
K19 过载保护并入
合并归属
负载事实陈列并入总览/人员负载，时段静默并入 K11；「保护人」立场保留为全局设计原则。
硬上限/拒单闸装在录入口，够不到真正的过载源头。
X4 对外举证并入
合并归属
自我回顾时间线并入 K12 变更记录，不单列；未来司法级留证另立、另议。
本机记录不满足法律真实性认定，本机哈希链也可被机主改写。
X10 对人关系并入
合并归属
动作归 K4、提醒归 K11，对象降为任务的 @字段；不建联系人实体、不算关系强度。
按字段删姓名不构成去标识，私人语境默认不进导出。
K17 平台终局并入
合并归属
降级为关系立场附注，并入 K14/K16 的维护预案，不独立建设、不产独立交付物。
吞并落空、冻结与现状无差别，无独立机制增量。

D后续 / 暂不建议（一行定位 + 理由）

这些本期不占路线，注明现在为什么不做、以后什么条件再谈。
K7 规划智能后置
暂不建议
整体后置：缺成对「预估 vs 实际」样本与工作量边权；样本达标后重启并重论增量。
无样本则估时校准不可运行，删减沙盘退化为日历幻觉。
K10 多AI角色撤并
暂不建议
宿主无常驻载体可挂班底；同读一份数据结论重叠、不独立；规则集并入规则承载。
单人空台账上无被考核对象，进程隔离不等于独立信息集。
K14 宿主解绑登记件
本期零投入
本期零投入登记；格式层消费 K16 快照，与 K16 合并计分，不重复计功。
当前规模抽内核无验收标准，不提前付维护税。
K15 商业分发撤并
暂不建议
付费墙空心化（无收费权、文本可再分发），且无已核验市场渠道；降为 K14 发布注记。
合规层与技术层同时空心，渠道第一环缺失。
X8 实物供应链撤回
暂不建议
剥掉审批/验收/库存后只剩任务+清单，属任务换皮；降为 project+task 使用切面。
个人采购离散低频，不产生多层物料展开。
X9 人生项目条件性
待举证
离散组并入 project；连续组（习惯/储蓄两模型）独立举证悬置，失败即降级为内容切面。
两模型参数集不相交，伪统一进一个 schema 不成立。

E能力边界汇总（画面与文案共同守住）

K2 边界
只做备注/证据链接的受限直写 + 关键变化展示确认 + 可撤销。
不展示自动改关键状态/负责人/排期。
K11 边界
只改善「打开后」的提醒整理与静音。
不承担系统级常驻主动推送（H6 是缺口，见 B 组）。
K18 边界
只读分发 / 单向出站，不是双向同步；目标平台待举证。
外部为唯一事实源，本地只留「已发出」日志。
X6 边界
业务完成 ≠ 复盘定稿；草稿证据不足留白，不编造。
无积分/连胜/徽章动效，仅文本归档。
X7 边界
愿景/OKR 与习惯两层都保留，仅建议分期（愿景/OKR 先）。
不伪造全勤曲线；单人保留率待长期观察。
K12 边界
只增日志 + 物理删除权优先；N/M 描述统计、小样本不下结论。
不做防篡改链，不作法律举证。
