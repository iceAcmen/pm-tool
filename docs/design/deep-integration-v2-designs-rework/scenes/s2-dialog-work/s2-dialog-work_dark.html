什么时候用：白天在 dsh 里围绕 G3验收项目边聊边推进、说着话就把该记的事记下来时。

你点什么：①在对话里说「帮我把这段说明补到 R-07 备注里」；②聊天中自然带出「我周三前给评审版」「这周要补截图凭证」这类承诺；③说「这个会话先挂到 T-102 上，待会儿接着做」；④会话里贴了附件、发生了文件改动。

系统替你做什么：K2 把要写进备注/证据链接的变化先展示成预览，你确认后才写入、可撤销；K4 把聊天里的承诺整理成待办建议（观察模式，不自动进箱），你逐条确认才进待办；K9 把会话单向结存到任务上，高置信自动挂、可撤销，低置信你一键采纳；K3 把会话内的文件与改动收成证据候选，你点归属才落盘。

你看到什么结果：对话里出现「待确认的承诺建议卡」（预填标题+到期占位）、「将写入备注」的变化预览卡（确认/取消）、会话挂上任务后的回显、证据候选的归属确认。

和现在有何不同：以前承诺散在聊天里找不到、备注要自己切到任务页手改；现在说一句即可沉淀，关键变更先给你核对，写错可撤销。
