# S5 长期沉淀：档案多年可读，目标上下连通（K16 · X7 · K12）

> 纯设计示意，不改产品源码/配置/依赖，不 push，不生成云文档。页面内全部为虚构示例数据。

## 一、五问白话叙事

- **什么时候用**：项目结项后想留一份多年后还能看懂的档案；或者想看清「这些项目到底为了什么」，把项目挂到目标下面。
- **你点什么**：在交付物/里程碑处点「归档结项」；或进项目概览看「关联目标」行；也可以对 AI 说「帮我起草 Q4 目标归属」。
- **系统替你做什么**：
  - K16：把项目存成通用可读格式，字段说明字典随档案一起打包，打包时自动核对，对不上当场报错；结项时生成一份不再刷新的静态叙述（结项切片）。
  - X7：愿景 → 年度目标 → 项目单父归属；AI 代起草归属建议由人确认，未确认进收件区、季度集中清空。
  - K12：记录 AI 改过什么，日志只增、可物理删除。
- **你看到什么结果**：
  - 结项档案页：档案包三件（通用格式数据 / 字段说明字典 / 结项静态叙述）+ 字段核对通过条 +「结项切片 · 不再刷新」标签；
  - 项目概览「关联目标」行：软关联可见、不计权重；
  - 归属建议卡：采纳 / 忽略双按钮；
  - 习惯记录：空日如实留空、累计天数与最长段永久保留、2 天补记窗回填（分期待拍板，仅示意）；
  - 变更记录列表：每条可删除。
- **和现在有何不同**：以前结项即沉底、目标与项目脱节；现在多年后仍能看懂档案，目标上下连通。

## 二、画面覆盖的能力

| 能力 | 画面落点 |
|---|---|
| K16 档案最小保存包 | 结项档案区块：通用格式 + 字段字典 + 一次性静态切片；构建期字段核对，漂移当场报错 |
| X7 愿景/OKR 层（本期先做） | 愿景层 → Q4 目标（主归属单父）→ 项目；软关联行可见不计权重；AI 代起草 + 人确认 |
| X7 习惯层（分期待拍板） | 分期提示条 + 月历示意（空日留空、断签重置 0、累计永久保留、2 天窗回填），本期不承诺 |
| K12 回滚账本 | 右侧「变更回看」：只增日志、N/M 描述统计、每条可物理删除 |

## 三、能力边界（画面与文案双查，不夸大）

- **K16**：只承诺多年后仍能打开、看懂；**不承诺**可复现当时工作、**不承诺**再生成一模一样成品；撤长期迁移器/周期固化。
- **X7**：愿景/OKR 层与习惯层两层都保留，仅建议分期（愿景/OKR 先）；不伪造全勤曲线；单人保留率待长期观察。
- **K12**：N/M 为描述统计，小样本不下失败结论；不做防篡改链、不作法律举证；删除权优先（可物理删除）。
- 常驻主动推送（H6）不在本场景承诺内；K11 只改善打开后提醒。

## 四、专家方法落实记录

- **design-human-ai-workflow（AI 控制点 propose/confirm）**：归属建议卡采用「AI 代起草（propose）→ 人确认（confirm）」分工，未确认不进主档、进收件区；归档动作由人触发；采纳/忽略按钮把裁决权留在人手里，AI 不直接写归属。
- **review-product-plan（非目标显式 + 撤并连理由）**：页面在边界注里写明「本档案不承诺可复现/可再生成」「不做防篡改链/法律举证」；习惯层明确标注「分期待拍板、本期不承诺」，不把未做的事画成已上线。
- **ui-ux-pro-max（token/热区/语义色/浅深独立）**：沿用 dsh 浅深两套独立 token；可点元素热区 ≥34–44px；进行中/达成/警示/风险用既有语义色；计数用 mono + tabular-nums。
- **ux-ui-audit（可达性）**：信息不只靠颜色区分（标签 + 文字双编码）；按钮均有可见文字标签；浅深两态分别核对对比度；键盘可点（原生 button + onclick）。
