被淘汰 / 撤并方案（概念页均含不推荐理由）

K5 会议流、K7 规划智能（后置）、K10 多 agent 角色、K15 商业分发、K17 平台终局（附注）、K19 保护面（撤除待拍板）、X4 对外举证（归并 K12）、X8 实物供应链、Y1a 代理缔约（并入 C3）、Y1b 信创等保（降知识清单）——每页均为「概念可视化 + 不推荐理由」，理由引用终局台账致命攻击（如 AI 非民事主体不能独立缔约、本地自录无外部时间锚、npm 市场客观不存在等），不以好看原型掩盖论证风险。
红线自查摘要：X6 三层触发默认锚 L1、证据不足留白不编造、完成态不与复盘定稿绑定；K11 无系统级推送假象（H6 主动触达悬置）；X9 分发默认不带敏感域 + PIPL 第 23 条单独告知；示例数据全部显式标注，无真实业务数据/生产 API。
