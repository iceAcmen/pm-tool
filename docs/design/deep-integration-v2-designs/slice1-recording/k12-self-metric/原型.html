回滚账本定位：变更流水记录，不做操作回滚引擎

账本只回答「这条记录被谁、在何时、改成什么」，供人回看与手工订正；不承诺自动逆操作、不做防篡改哈希链、不做法律举证包（X4 归并）。独立记录编号 + 只增日志（append-only），同时保留物理删除/归档通道，删除权优先。

采纳率 N/M：达标前只展示描述统计，不下失败裁决

分子 N=被采纳/签字的建议数；分母 M=唤起过且进入人裁决的建议数；未唤起（模型根本没提出）从分母分离，不计入失败；零调用不裁决。样本不足（Wilson/精确区间门槛未达）只给 N/M 描述统计，不给成败结论。切换样本量观察两态。

来源档降「提示」：不显示可靠度档位，不进排序权重

agent 自动建议、手动录入、外部粘贴只作为来源提示 chip 展示，不做 A/B/C 可靠度分级，也不参与列表排序权重；可靠度判断留给人。
