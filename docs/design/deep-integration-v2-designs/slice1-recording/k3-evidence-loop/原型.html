开工最小绑定：agent 代挂草案，人一键确认（不等 K9）

会话开始时 agent 依据首条对话识别在册任务，代挂一个主归属草案；人确认或忽略。绑定任务仅作主归属，会话内其他改动不整会话错挂，进候选池由人认领。机制先于 K9 完整会话编排存在。

依据：本会话首条对话提及该任务；低置信落空则不绑定，退回人工贴 evidenceUrl。

会话结束 · 证据候选（人确认归属，不自动落库）

自动收成只覆盖已绑定会话内的工作痕迹；每条线索带来源类型提示（非可靠度档位、不进排序权重）。客观改动类可进证完成侧；present 声明类线索不作完成证据。未绑定会话的改动进孤儿池，认领成本与现状手动贴链接同量级，如实承认。

覆盖边界（诚实声明）

01
会话内支流
只对 dsh 会话内完成的工作痕迹自动收成；绑定率（代挂且被确认的会话/相关会话）待 K12 计数，E6 无实测，不预先主张全量闭环。
02
公司系统侧
不承诺覆盖飞书项目/Jira 等公司系统动作；外部证据走现状人工 evidenceUrl 粘贴与 K18 单向链接登记。
03
git 降级线索
非仓库/桩 git、手动编辑等五类失效静默跳过记日志，渠道失效退化为人工粘贴，不报错、不伪造。

本页为设计原型，全部条目为示例数据；绑定率、会话内动作占比为 E6 待 K12 本机计数项，未包装为实证。
