L2 · 寄生 K3/K4：一致性复核与缺口清单，上游未落地不启动

L2 不是独立评判引擎：一致性复核、证据否证、缺口清单全部以 K3 证据原料、K4 承诺原料为输入；上游未落地时保持占位，不凭空生成结论。输出边界 = 一致性 + 缺口，不背书完成、不下完成裁决。

L2 待命中：K3 证据原料 / K4 承诺原料尚未进入本机样本，本层不启动、不生成结论。
G1
承诺与记录不一致
K4 留痕「周五前发张工」，记录内无对应到期/进展；仅列出，不改状态。
G2
同源叙述不作证据
present 声明「应该够了」与会话自述为同一来源，不互相佐证；不进证完成侧。
G3
重复缺口合并为持续项
同一缺口跨会话重复出现，合并为一条持续项，按出现期数升级提示等级，不堆重复条目。
未覆盖 ≠ 未完成：L2 只说明「本次原料里没看到对应证据/承诺」，不等于判定任务没做完；完成与否的裁决权始终在人，L2 不输出「已完成/未完成」结论，也不据此自动流转状态。
