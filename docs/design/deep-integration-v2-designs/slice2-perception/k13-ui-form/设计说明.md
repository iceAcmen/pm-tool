# K13 UI 形态与宿主原生寄生 · 设计说明

> 终局判定：接近饱和（裁判 A/B 修正采纳）。
> 组合定位：**第 2 层寄生/登记层**（零或低主动投入，保留 9 视图）。
> 原型：`原型.html`（只读投影三态 + 设置卡分工 + 命令通道；示例数据；浅深两态）。

## 1. 事实/场景核对

- E5：宿主详情页徽标位 subject 绑定插件管理页，主工作屏无自由徽标位；宿主设置卡为 Config volatile 即时表单；本机 Web 只信 loopback。
- E4：对话内卡片与既有 9 视图自绘面板构成双状态源，同一任务两处渲染且可漂移；零会话场景卡片整体缺席。
- E5：`defineTool`/工具结果可携带 UI 卡片；`/pm ...` 命令人直接触发、不耗模型轮次。
- C6：alpha 上游只读、破坏性变更登记。

## 2. 设计：改变了什么

### 结构
1. **对话卡片 = 只读投影单真源**：真源在本地数据，卡片只投影，经唯一写通道回写，无第二状态库；单动作（采纳/忽略）。
2. **版本闸 + 失效遮罩**：卡片携快照版本/时间戳，动作前服务端比对当前版本，不符拒收并出窄错误行（「记录已变更，请回面板处理」）；已处理/已变更旧卡片置灰禁用，过期可点面关闭。
3. **设置卡只放技术旋钮**：模型车道、临期窗口天数、过载阈值、mute 开关；13 项业务口径（健康分权重、战略权重、归属裁决、规则阈值、草稿流口径）留自绘面板。
4. **命令行补充通道**：`/pm due`、`/pm health`、`/pm board-export` 等人触发，不替代面板。
5. **撤回**：详情页徽标、对话内业务卡片双状态源、系统全局快捷键（实为窗口内命令注册）。

### 交互（原型三态）
- 正常可采纳 → 采纳后转已失效遮罩；
- 已处理/已变更 → 置灰禁用；
- 版本不符 → 点采纳出窄错误行并置灰。

### 视觉
- 投影卡用 elev 底色区别于面板实体卡；版本戳 mono 小字；错误行单行窄回显，不扩成反馈面板；撤回项删除线陈列。

## 3. 采用的专家方法

- **design-human-ai-workflow（stale state 与恢复）**：版本闸处理陈旧投影，失效遮罩关闭重复采纳路径，错误行给出恢复动作（回面板）。
- **ux-ui-audit（最小寄生）**：能借宿主壳位才借，设置卡容量/语义错配的不塞；面板纯视觉派生能力不退命令行。
