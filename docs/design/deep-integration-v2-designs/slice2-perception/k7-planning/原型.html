K7 · 规划智能（估时校准 / what-if 沙盘 / 延期红灯 / 只读 DAG）

整体后置 · 当期不占路线的概念可视化（示例数据）

裁判 A/B：后置（成立） 终局：饱和（当期） 重启条件化事件，非本期承诺 原型内全部为示例数据，不接生产 API
当期结论：第一期不交付任何 K7 件，不占当期路线

两条致命独立于 H12（本机无成对「预估 vs 实际」原料、无工作量边权），后置使「长期占位、当期空转」的攻击对象消失。本页仅作概念留存与重启门槛登记，不渲染为可操作功能。

概念 A · 估时校准闭环

照系统性偏误，不做精确预测

概念形态

完成任务收实际工时，按同级同类聚合历史分布（中位数+四分位）给新任务建议区间；逐次自我修正偏差类别。

当期缺口（E1 源码事实）

task.ts 无 estimate 字段；effortHours 在 schema 内但全仓 0 填充，无成对「预估 vs 实际」样本，闭环无物可照。

重启条件

计划估时字段双录 + 长期成对样本达标；镜子只照可见动作工时，无 K3 痕迹的沟通任务不计入均值。

概念 B · what-if 删减沙盘

不改库推演「挪几天 / 减几条」

概念形态

纯前端临时拖日期/减负载，用现有 criticalPath/slack 重算关键链移动与里程碑冲击，情景不落库、可对比 2–3 版。

当期缺口（E4）

无工作量边权，影响面闭包为空，只能平铺；无边隐藏影响面声明，退化为日历幻觉，与「不伪精确」原则冲突。

重启条件

边权原料齐备后重启；重论证相对现有甘特/关键路径视图的增量，不与现状重叠交付。

概念 C · 延期红灯 + 只读 DAG

达标才亮灯，DAG 只读展示

概念形态

趋势箭头只在可比时点 ≥2 时显示；DAG 由 predecessorIds 派生，只读、不编辑、不落库。

当期缺口（E2/E1）

可比时点 <2 时单点决定箭头方向，随机面不可隐藏；沟通任务无痕导致可见性偏误冒充全量工时偏误。

重启条件

n<2 不显示箭头，只显绝对计数+样本量标注；可见/不可见分层口径随重启定义（L-K7-01）。

重启门槛（条件性事件，任一不满足不启动）

  • 原料达标：成对「预估 vs 实际」样本长期累积达标（H12 数十项目改善规模，但规模扩大≠校准样本齐备）。
  • 增量重论证：重启时重新论证相对现有甘特/关键路径/逾期派生视图的净增量，不默认成立。
  • 口径随重启：可见/不可见分类依据（无痕迹=不可见为默认口径；「有痕迹但不等于工时」的边缘归类）届时定义。
可比时点 <2：不画趋势箭头，只显示绝对计数 + 样本量标注（示例：2 条样本 · 不判方向）
  • 攻防关系：R2-C-K07-01（可见性偏误）→ 镜子分层声明口径；R2-C-K07-02（当期全禁用/空转）→ 整体后置；R2-C-K07-03（无边闭包为空）→ 退平铺声明；R2-C-K07-04（n≤2 单点箭头）→ 不画箭头只显计数。
  • 定位：后置/悬置，不进本期核心组合；重启为条件性事件。示例数据，未接生产 API。
