# K7 规划智能 · 设计说明（后置概念页）

> 终局判定：饱和（当期），**整体后置（裁判 A/B 后置成立）**。
> 组合定位：**后置/悬置，不占本期路线**；本页为「概念可视化 + 不推荐当期理由」留存。
> 原型：`原型.html`（概念虚线卡 + 重启门槛；示例数据；浅深两态）。

## 1. 事实/场景核对

- E1 源码事实：`core/task.ts` 无 estimate 字段；`effortHours` 在 schema 内但全仓 0 填充；`predecessorIds` 存在（只读 DAG 原料具备）；completion-history 只数完成条数不数工时。
- E4：无工作量边权时 what-if 影响面闭包为空，只能平铺；E2：非稳态均值布尔化（n≤2 单点决定趋势方向）。
- E1：无 K3 痕迹的沟通任务记 0，可见性偏误冒充全量工时偏误。
- H12（数十项目、通道稳定）改善样本规模，但不消除「成对估时样本」门槛。

## 2. 设计：为什么当期只留概念页

三条概念（估时校准闭环 / what-if 删减沙盘 / 延期红灯+只读 DAG）以**虚线框概念卡**并陈，每张含「概念形态 / 当期缺口 / 重启条件」三段，不渲染为可操作控件——后置意味着当期空转对象消失，页面不提供假的输入框与按钮。

- 概念 A 估时校准：照系统性偏误而非精确预测；重启需计划估时字段双录 + 成对样本。
- 概念 B 删减沙盘：无边权时退平铺、不伪精确；重启需边权原料 + 增量重论证。
- 概念 C 红灯+只读 DAG：可比时点 <2 不画箭头，只显绝对计数+样本量。

### 视觉
- 虚线边框统一表达「未启用概念」，与可交付卡片（实线）区分；重启门槛用实线收口，表达条件是硬门。
- 浅深两态真设计；无大字数字卡、无动画。

## 3. 采用的专家方法

- **review-product-plan（non-goals 与重启触发器显性化）**：后置方案必须让「不做什么 / 何时重新评估」可见，避免长期占位。
- **html skill**：概念页无交互控件（除主题切换），不造僵尸按钮；E1/E4 证据标注。

## 5. 重启门槛（非本期承诺）

1. 成对「预估 vs 实际」原料达标；
2. 相对现有视图增量重新论证；
3. 可见/不可见分层口径（L-K7-01）随重启定义。
