## 2. 设计：改变了什么

### 结构
- **阈值触发隐藏**：在持项目 ≤ 默认阈值 5（或未主动打开）时，组合面收起为一行虚线入口；超阈值或主动打开才展开。原型提供 4/6 项目模拟切换演示联动。
- **三档轻选 + 空置不给结论**：每项目记 高/中/低/中性（默认中性）；空置期只陈列紧急度事实（逾期数/临期数/最近活动），**不输出保/缓/砍结论**，切断「单紧急轴冒充双轴决策」的伪路径。
- **打开时置顶**：待决策区在面板打开时醒目置顶；主动到期召回（reviewBy）显式绑定 H6 里程碑，当前不宣称主动触达。
- **不新建独立视图**：未完成/P0/逾期计数并入现有看板项目分组列；`isExemptFromActiveStats(project, audience)` 预留 audience 参数，external 不实现。

### 交互
- 三档分段选择仅记录人的偏好，即时 toast 明确「不生成保/缓/砍结论」；空置行显示「未评级 · 仅陈列事实」。
- 阈值模拟切换联动隐藏/展开，避免把隐藏态画死。

### 视觉
- 隐藏态用虚线折叠条区别于实体卡片；事实列用 mono 计数，状态色仅用于逾期/临期数字；无大字数字卡。

## 3. 采用的专家方法

- **design-human-ai-workflow**：权重是人给的偏好（human decides），系统不替人下保/缓/砍裁决；AI 不生成战略结论。
- **ux-ui-audit（最小干预）**：复用现有看板分组列承载聚合，不新建平行视图，消除信息差重复。
- **html skill**：阈值/选档真实状态机，无僵尸按钮。
