# K9 会话载体寿命绑定与执行编排 · 设计说明

> 终局判定：接近饱和（裁判 A/B 修正采纳）。
> 组合定位：**第 1 层会话采集主线**（最小绑定先于完整编排；K3 最小绑定同源）。
> 原型：`原型.html`（单向结存 + 代挂建议 + 只读 DAG；示例数据；浅深两态）。

## 1. 事实/场景核对

- E5：宿主 `todo`/`goal` 为会话级（随对话存在），`session-query-sqlite` 为独立派生库/FTS5/单进程持有；`core/reminders.ts` 为纯离线派生。
- E4：显式人挂 taskId 与 H5（agent 代执行）互斥 → 改 agent 代挂建议 + 人一键确认；人确认保留 C3 裁决位。
- E5：`sessionQuery` 读 alpha 日志格式，残余耦合登记；公司系统动作无日志，原料缺口归 K3/K18。
- E4：规则白名单刹车在 PM 语义任务上无可穷举对象，默认关闭名存实亡 → 删除不留占位件。

## 2. 设计：改变了什么

### 结构
- **寿命单向结存**：会话级 todo/goal → 长寿台账，单向箭头，不双向镜像、不双向同步；绑定为会话↔taskId 关联元数据，不属 C3 约束的状态机落库写。
- **agent 代挂建议（两态）**：
  - 高置信：自动挂，条目上可撤销；
  - 低置信：建议条附匹配理由，人一键「采纳 / 忽略」，人不主动挂接、只裁决建议。
- **只读 DAG**：由现有 `predecessorIds` 派生，只读展示依赖，无拖拽/改边句柄；无边退树状平铺。
- **移交**：纯文件缺席队列移交 K11；扇出/无人值守/常驻/goal 刹车全部撤回。

### 交互
- 采纳→出现已挂状态条；忽略→建议条收起；自动挂可撤销；toast 标注示例。

### 视觉
- 短命盒用 elev 底色区分于长寿实体盒；建议条高置信用绿边、低置信用中性边；DAG 等宽字体、只读虚线标签。

## 3. 采用的专家方法

- **design-human-ai-workflow（自主权分级）**：AI proposes（低置信建议）/ AI acts with confirmation（高置信自动挂但可撤销），人保留采纳/忽略/撤销；不授予 AI 状态机写。
- **ux-ui-audit**：残留耦合点与原料缺口如实标注移交，不在 K9 内伪造覆盖。
