# X7 纵向愿景 OKR + 习惯层 · 设计说明

> 终局判定：饱和（正式方向；裁判 A/B 采纳，用户 §三 拍板「两层都要」）。
> 组合定位：**本期核心组合第 3 位（愿景/OKR 层）**；习惯层是否同批待拍板清单第 5 条。
> 原型：`原型.html`（愿景树 + 归属建议 + 习惯打卡双态；示例数据；浅深两态）。

## 1. 事实/场景核对

- E2：OKR 单父归属（primaryOkrId）低估多目标；软关联需独立可见但不计权重。
- E2：Lally 2010 维持 66 天窗口仅适用简单/每日/线索固定行为，不外推复杂习惯；企业习惯软件 42% 保留率转述仅登记。
- E5：宿主会话派生习惯痕迹；X6 保留事件触发即时复盘；K11 承担周期触发呈现。
- 用户 §三：愿景与习惯两层都要，推翻弱候选「仅 K8 标签」判定。

## 2. 设计：改变了什么

### 结构（两层并陈，形态 A 采用 / 形态 B 对照）
1. **项目之上 · 愿景树**：北极星愿景 → 年度 OKR → 项目；单父 primaryOkrId 主归属（实心点）；软关联「关联目标」虚线行可见、不计入主归属权重。
2. **归属建议**：agent 代起草归属建议（附依据），人确认/忽略；未确认进收件区，季度回访集中清空，不静默落库。
3. **项目之下 · 习惯层**：会话派生 + 一键「今日完成」轻补记；空日如实留空，不伪造全 0 曲线；完成率分母只在有记录的活跃周期计。
4. **streak 连续/累计分离**：连续 streak 断签超窗重置 0；累计档案（最长段/累计天数）永久保留不清零；2 天补记窗内回填保持连续。
5. **周期触发归 K11**：每日提醒/季度回访由 K11 呈现层承担，X6 仅事件触发即时复盘，两套周期提醒不并行。

### 交互（原型）
- 点今日格记完成 → 连续 streak +1；补记窗回填最近空日；
- 归属建议确认/忽略 → 建议条收起；
- 形态 A/B 并陈对照，不做无意义切换。

### 视觉
- 主归属实心点 vs 软关联虚线点；连续/累计分两盒并列，避免一个数字同时表达两种语义；空日格如实留白。

## 3. 采用的专家方法

- **design-human-ai-workflow（AI proposes / human confirms）**：归属建议与习惯派生均为 AI 提议，人确认后落库；季度回访集中清理未确认项。
- **review-product-plan（形态并陈与待验证显性化）**：独立层 vs 复用 K8/K11 两形态并陈，标注论证结论与 E6 待验证。
