## 采用的专家方法

- **design-human-ai-workflow**（vendor/product-os/skills）：自主权分级（AI proposes / AI acts with confirmation / human decides）用于 K9 代挂建议、K13 版本闸、X7 归属建议；stale state 恢复用于 K13 失效遮罩；缺席≠拒绝用于 K11。
- **review-product-plan**（vendor/product-os/skills）：non-goals 与重启触发器显性化用于 K7 后置页、K10 撤并页、X7 形态并陈；证据等级 E5/E6 标注。
- **ux-ui-audit**（vendor/ux-ui-skills/skills）：最小干预/最小寄生、状态覆盖（空/陈旧/错误）、证据分级用于全部单元自检。
- **html skill**（.skills/html）：单文件自包含、原生 JS、无僵尸按钮、shot.py 确定性自检、内联 SVG favicon、浅深 token 双态。
