不推荐理由（三条，均经攻防核验）

理由一 · 合规层空心化

没有可合法收费的标的

各自持 key 时作者对 AI 消耗无收费权；代持 / 转售套餐额度直接落入个人计费计划 §1.1 红线；文本方法论包零边际成本、MIT 允许再分发，付费墙不可闭合。

理由二 · 渠道层缺失

无官方市场、无自然流量

dsh 无已核验公开插件市场；npm 上包从未发布。长尾分布下多数包周下载 0–10，分发链路第一环即缺失，营销漏斗无入口。

E1 arXiv:2003.03471 长尾（适用：全生态分布，不推定单包零下载）
理由三 · 受众类型不重合

阅读 / 汇报 ≠ 安装使用者

H11 的外部受众是团队 / 朋友阅读与汇报，不是安装 alpha 插件并自配 key 的使用者；熟人阅读不经 registry 搜索，自然流量缺失不被 H11 解除。
