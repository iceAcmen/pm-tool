## 设计前提
- 事实（E1 本机核验）：`packages/dsh-pm-tool/package.json` `"private": true`、npm view E404、无 LICENSE/CONTRIBUTING；个人计费计划 §1.1 红线：套餐额度不能用于 API 调用 / 代持转售。
- 事实（E2）：MIT License 允许复制 / 修改 / 再分发，付费文本包无法律排他。
- 事实（E3，标适用条件）：Anthropic 2026-02 起禁第三方订阅凭证中继；适用条件为平台掌握计费闭环时才出手，小规模自用不触发。
- 用户假设（H11）：受众=团队/朋友/公开分发的阅读与汇报，≠npm 安装使用者。
- E1（arXiv:2003.03471）：npm 长尾多数包周下载 0–10，适用全生态分布，不推定单包零下载。

## 改变点
1. 不建任何商店/定价/市场界面；改为「原主张三块 → 去向」的归并映射图：收费半臂删除、免费发布归 K14、方法论免费附赠。
2. 不推荐理由三条与归并结果同屏：合规空心化 / 渠道缺失 / 受众类型不重合，每条带证据等级与出处。
3. 残留登记 E6（履历背书量化、§1.2 合规风险自担）单独陈列，不伪装成结论。

## 采用的专家方法
- review-product-plan §6 非目标与取舍：把「不做什么」显式写出，替代默认的市场叙事页面。
- ux-ui-audit 证据分级：E1/E2/E3/E5 与 E6 分色标注，E3 标适用条件，E6 只登记。
- frontend-design：撤并页不套 SaaS 卡片套件，用「主张→去向」映射结构承载清点关系。

## 与攻防结论的关系
- K15-01（付费分层合规+技术空心化，致命）：收费半臂删除后对新形态撤销，本页保留历史记录。
- K15-02（市场渠道不存在，致命→局部）：H11 只解除「无第二用户」，不解除「无官方市场、无自然流量」，本页固定该事实。
- R2-E-K15-01（方向坍缩仅剩履历叙事）：撤并成立，履历为目的陈述非机制。
- R2-E-K15-03（最小治理无响应通道，履历背书 E6）：登记项保留。
