# X4 对外举证 · 设计说明

## 终局定位
- **台账判定**：归并 K12；法律承诺撤回；裁判 A「归并 K12（法律承诺撤回；自我回顾时间线材料，非第三方可采信）」；裁判 B「归并 K12；法律承诺撤回」。
- **推荐档位**：**归并/撤回**——不新建举证包；仅保留 K12 审计流的自我回顾用途与边界标注。

## 设计前提（红线）
- 本页必须明示「自我回顾时间线材料、非第三方可采信」，不得用好看原型洗掉该限制。
- 事实（E2）：民诉法 Art93/94 证据类型中，当事人自录材料证明力弱、可被质疑；PIPL Art47 删除权。
- 事实（E1）：时间戳来自本机可改时钟，无外部时间锚；本地文件可被本机改写，「只增」不等于「不可篡改」。

## 改变点
1. 顶部边界横幅：自我回顾材料、非第三方可采信，三项局限（证明力弱/可篡改/本机时钟）一次说清。
2. 原承诺三行划除 + 逐条理由：不可篡改举证包 / 法定留存独立出示 / 删除留痕对抗删除权，各带证据等级。
3. 现存能力：K12 只增审计流同载体，限自我回顾与述职自述。
4. 未来条件性储备另立登记：外部时间戳/公证/区块链存证，需外部锚且受 PIPL 约束，本期不实现。

## 采用的专家方法
- review-product-plan：撤回的承诺仍可见（划除而非隐藏），防止后续轮次复活。
- ux-ui-audit 证据纪律：E1 本机事实与 E2 法律条文分注，不把法律条文写成已验证结论。
- 视觉：边界声明用红色描边横幅（语义色=撤回/警示），不堆徽章；划除线表达承诺作废。

## 与攻防结论的关系
- R2-F-X4-01（法律/技术双重不成立）：三条理由逐条闭合。
- R2-F-X4-02（PIPL 删除权冲突）：删除留痕承诺划除。
- 归并去向：K12 审计流同载体，不另建模块。
