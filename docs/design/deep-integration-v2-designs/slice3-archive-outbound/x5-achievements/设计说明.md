# X5 成就库 · 设计说明

## 终局定位
- **台账判定**：条件性采纳；裁判 A「条件性采纳（述职素材库去证明力；导出闸门排待核栏）」；裁判 B「条件性采纳（素材库非证据链；导出闸门排待核）」。
- **推荐档位**：**附加层**——述职素材库，不做终身证据链。

## 设计前提
- 原始主张（D3-N3）：跨项目归档可带走成果，面向晋升/求职/述职的个人职业信用层。
- 攻防修正（R2-F-X5-01/02）：去证明力——本地自述不可作第三方信用证明；与 X4 撤回的举证承诺划清界限；外部链接/证明人仅为过渡字段。
- 边界：选择性素材，非完整贡献记录。

## 改变点
1. **自述/证据分栏**：每条素材分「自述数字（本人陈述）」与「可核验证据/外部链接/证明人」两栏；待核/已核验状态标签。
2. **导出闸门**：勾选导出时，自述待核条目默认排除，实时显示「N 条待核将被排除」；仅已核验条目进入导出稿预览。
3. 边界声明：非完整贡献记录、非证据链；外部字段不保证采信。

## 采用的专家方法
- design-human-ai-workflow 证据区分：本人陈述 vs 外部可核验材料在 UI 上分栏，导出时系统按核验状态过滤，避免自述被包装成证明。
- ux-ui-audit：导出闸门给实时计数反馈，排除动作可见（toast + 预览），不留静默丢弃。
- 视觉：表格固定列宽；待核用 warn 色、已核验用 ok 色，文字标签与颜色双编码。

## 与攻防结论的关系
- R2-F-X5-01（本地自述无证明力）：去证明力定位 + 导出闸门闭合。
- R2-F-X5-02（非完整贡献记录）：边界声明闭合；与 X4 举证撤回保持一致。


## 验证结果（shot.py 实测）
- 浅态 desktop/mobile pass；深色态 pass；自述/证据分栏、待核标签、导出闸门计数与预览由代码审查。
