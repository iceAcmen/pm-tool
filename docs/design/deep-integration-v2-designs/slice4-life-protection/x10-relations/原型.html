不立联系人实体：对象只是 task 上的一个字段

不建联系人档案、不做关系强度计算、不做人脉网络视图。动作（答应/承诺）归 K4 承诺浮出，提醒归 K11 呈现层，对象降为 task 的 @对象字段。

回电确认 Q3 预算口径（示例任务）task #t-104
@对象字段@ 协作方 · 采购对接人（示例化名）
承诺事项回电确认 Q3 预算口径（动作由 K4 浮出、人归类签字）
到期2026-10-22（提醒归 K11，不另建跟进提醒机制）
备注语境私人事件/家庭信息等语境细节默认不进导出（示例位）

动作层

「答应某人的事」归 K4 承诺浮出，人归类签字。

提醒层

到期跟进 归 K11 呈现层，不承诺跟进价值。

对象层

仅余 task 的 @对象字段，无联系人主库，更正删除权归通讯录。

导出前：按「是否可识别」逐条判定，非按字段删

PIPL 第 4 条个人信息含已识别/可识别（含间接识别）；仅删姓名/电话/职务而保留称谓+语境，熟人圈仍可间接定位到人。逐条判定每条文本是否可识别，再决定泛化或剔除。

「@王总 答应下周回电确认预算」（示例称谓）
称谓 + 职务组合，接收方同圈可定位到人 → 可识别
默认：泛化（不留姓氏+身份组合）
「上次聊到孩子升学，顺便问问」（示例语境）
私人家庭细节，与承诺无关 → 默认剔除，不进导出
默认：剔除语境，仅留承诺事项与到期
「回电确认 Q3 预算口径 · 到期 10-22」（承诺本体）
无个人识别信息，仅事项与日期 → 可带
默认：保留
PIPL 第 23 条：向他人提供个人信息需告知并取得单独同意；告知与同意由用户在工具外完成，工具不内建同意记录、不代宣称已取得同意。

泛化后导出预览：化名 + 仅承诺事项与到期

公开分发走化名、不留回溯线索；私人语境默认剔除。预览随上一页逐条判定实时更新。
