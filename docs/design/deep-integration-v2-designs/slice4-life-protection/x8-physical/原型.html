概念可视化：该方向若立项，会是一套供应链管理模块

以下为概念推演，展示「独立方向」原本主张的完整形态；用于让决策者看见被撤回的是什么，不是当前产品功能，也不代表推荐立项。

概念推演框 · 六件主张过的供应链能力

BOM 多级物料展开

成品→子件→零件多层拆解，数量定额。

采购单 / 供应商档案

供应商名录、报价历史、联系人台账。

库存结存

现货数量、出入库流水、低库存阈值。

到货验收 / 自动核销

到货比对采购单，自动勾销待办。

审批流

采购申请→审批→下单多级流转，第二审批角色。

待回填提醒

未到货到期主动提醒跟进。

概念示意 · BOM 多级树（仅推演，当前无此结构）
成品：家庭 NAS 装机（示例）
主板 / 硬盘 ×2 / 内存 / 电源
硬盘 → 4TB ×2（定额）

E1 事实：个人采购为离散低频单条目，不产生多层级物料展开，当前无 BOM 对应物。

机制增量判定：逐功能映射现有七实体，全部映射成功即换皮

致命攻击 G8-X08-02 的方法：把候选每个功能逐一映射到现有实体，剥掉组织机制后剩余=task+清单，无独立状态机、无新字段、无自带触发。

概念功能现有实体承载（使用切面）缺失 / 剔除项
一次性采购清单project（本次采购）+ task 列表逐件勾选无多级 BOM 展开
到货日期 / 回填跟进task.dueDate；提醒归 K11 呈现层无自带常驻触发（C7）
验收凭证task.evidenceUrl 人工粘贴无自动到货核销
缺货 / 延误风险risk-issue 实体登记无库存结存台账
供应商 / 报价task 备注文本（仅自用记录）无供应商档案实体
多级审批流无第二审批角色（H11），剔除审批流整体剔除

结论：成立切片由 project+task 承载，不产生方向增量；公司采购 / 库存归公司系统侧（H2），不在本工具展开。

不推荐独立立项的理由（引用台账致命攻击）

G8-X08-02 · 致命（框定性）

剥掉组织机制后剩余=task+清单，属任务模型换皮

审批流、自动验收、供应商档案、库存结存全部剔除后，没有独立状态机；作为独立方向不成立，作为现有实体使用切面可被吸收、无需立项。

G8-X08-03 · 显著（E6）

个人 BOM / 库存需求无证据

个人采购离散低频单条目，不产生多层物料展开；需求 E6 待证，H11 当前受众无第二审批角色。

G8-X08-05 · 显著

无常驻提醒下未回填条目悬挂

C7 未解除，不设自带触发；待回填提醒移交 K11 呈现层，不由 X8 承诺。

G8-X08-06 · 显著（预防登记）

为供应链追加空置字段产生认知税

撤回独立方向后零新增列，攻击前提（追加字段）随之消除，作为预防意见登记。

成立切面（保留，不立项）

一次性采购清单由现有 project+task 承载：project=本次采购，task=清单条目，dueDate=期望到货，evidenceUrl=验收凭证，risk-issue=缺货风险；提醒归 K11。无新实体、无新字段、无自带触发。

重启条件（登记，非本期承诺）：取得目标人群个人 BOM 需求的 E1/E3 证据，且 H11 出现第二审批角色；二者齐备后重估，不在本期路线。
