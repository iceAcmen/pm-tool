离散组：二值完成项直接并入 project，无新状态机

家庭、旅行、办证等离散项目与现有 project 完全同构（二值完成、离散枚举），换「家庭/旅行」标签不产生新状态机；隔离降为标签约定，不强制分文件，跨域总览不承诺自动聚合。

习惯模型：SRHI 自报自动化评分渐近曲线 + 单次缺失回弹

独立 schema 之一。度量单位=自动化评分（SRHI 自报），无金额、无利率；无完成点，不判 done/失败。与储蓄模型不共享状态机（R2-G-X9-01 伪统一已拆除）。

习惯模型 schema A · 度量：自动化评分 0–5

参数集：自报自动化评分、记录日期、缺失标记、2 天补记窗
状态：进行中（无 done / 无失败终态）

适用条件与边界

· 证据 E1：Lally et al. 2010（DOI 10.1002/ejsp.674），96 人 12 周自报，到达 95% 自动化平台 18–254 天、中位约 66 天。
· 适用条件：简单 / 每日 / 线索固定的健康行为；自选择样本、自报度量。
· 不外推：复杂习惯、专业医疗戒断、他人监督行为。
· 单次缺失不致命：曲线回弹，连续计数断签超窗重置 0，累计档案不清零。
E6 举证悬置：本独立 schema 是否成立待本机样本举证；举证失败则 X9 降级为 project 内容切面，本期不实现。

储蓄模型：金额复利累积（本金 / 利率 / 期数 / 支取），独立状态机

独立 schema 之二。度量单位=货币金额，参数集与习惯模型完全不相交，不合并、不共用曲线。

储蓄模型 schema B · 度量：货币金额

参数集：本金、每期投入、年利率、期数、支取记录、币种
状态：累积中 / 已支取（独立状态机，与自动化评分无关）

与习惯模型的边界

· 度量单位：货币金额 vs 自动化评分，不相交。
· 参数集：利率/期数/支取 vs 缺失标记/补记窗，不共享。
· 不伪统一进一个「连续模型」schema（R2-G-X9-01 闭合）。
· 不外推专业理财模型；本模型仅个人记账式累积演示。
E6 举证悬置：两模型独立成立条件待证；任一举证失败即降级，不另立 schema。

分发前敏感域检查：默认不带敏感域，工具只给检查入口

隔离为标签约定（非强制分文件）。导出/分发默认不带财务、健康等敏感域，宁可不带不误带（排除清单 E6 实现前的保守默认）。工具呈现检查入口与逐条勾选，不替用户完成合规判断。
