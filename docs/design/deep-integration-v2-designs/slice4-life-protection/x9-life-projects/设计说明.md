## 二、改变点（相对现状给出什么）

1. **离散组并入 project**：家庭/旅行/办证等二值完成项用普通 project 状态机 + 域标签（家庭/旅行/健康/财务）承载，不建新实体、不建新状态机。
2. **连续组拆两个独立 schema（不伪统一）**：
   - 习惯模型：SRHI 自报自动化评分渐近曲线 + 单次缺失回弹；无完成点、不判 done/失败；参数集=评分/日期/缺失标记/补记窗。
   - 储蓄模型：金额复利累积（本金/每期投入/年利率/期数/支取/币种），货币单位，独立状态机。
   - 两者度量单位与参数集不相交，不共享 schema（R2-G-X9-01 闭合）。
3. **隔离降为标签约定**：不强制分文件，消除跨文件聚合断裂；跨域总览靠标签筛选，不承诺自动聚合（R2-G-X9-02）。
4. **分发前敏感域检查入口**：财务/健康默认剔除，宁可不带不误带；PIPL 第23条告知+单独同意在工具外完成，工具只给登记勾选、不核验、不留存同意凭证、不代宣称已取得。

## 三、关键界面与状态（浅深两态）

- 四页签：离散组 / 习惯模型 / 储蓄模型 / 分发前检查，均有真实 handler。
- 两模型并列双卡，度量单位与参数集分区列出；曲线为确定性 SVG 概念示意，标注示例。
- 分发检查：敏感域行默认禁用勾选（剔除），工作域默认可带；同意勾选解锁导出按钮，预览只含已带条目。
- 浅深双套 token，SVG 描边用主题变量。

## 四、采用的专家方法

- **design-human-ai-workflow · context contract / system must never infer or retain**：敏感域由工具默认剔除并呈现检查入口，但告知与同意判断归用户（工具外），系统不代完成合规决策、不留存同意凭证。
- **E4 模型同一性判定（按度量单位与参数集是否共享）**：自动化评分与货币金额参数集不相交，据此拆 schema，拒绝一个「连续模型」伪统一。
- **E1 标适用条件**：Lally 2010 仅支撑简单/每日/线索固定健康行为的自报自动化度量，不外推复杂习惯/专业医疗；E6 举证悬置显式标注。
