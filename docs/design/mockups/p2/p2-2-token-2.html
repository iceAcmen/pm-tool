设计 Token 2.0

把现网两层 token（旧语义层 --pm-* 与 dsh-flat 层 --*）收敛为单层语义 token，补齐图表序列、阴影、动效 token，消除 token 漂移根源。宿主别名仍优先，fallback 兜底。

单层语义浅 / 深双值宿主别名优先渐进迁移不一次性切换

现状（两层，易漂移）

--pm-ink / --pm-surface（旧语义） --ink / --surface（dsh-flat）
两套命名并存，部分视图消费这层、部分消费那层，导致同角色不一致。
→

Token 2.0（单层语义）

--color-surface / --color-ink --color-prog / --color-chart-1
一个角色一个 token，内部映射宿主别名 → fallback；补全图表/阴影/动效。

迁移与废弃顺序

渐进，不一次性切换
阶段 1

建立新 token

  • 定义 --color-* 单层
  • 映射宿主别名 + fallback
  • 补未定义/缺失项
阶段 2

逐视图切换

  • 新页面消费新 token
  • 旧 token 作为别名保留
  • 每视图单独验证
阶段 3

别名收敛

  • 确认无旧 token 引用
  • 旧 token 标记 deprecated
  • 保留一个版本周期
阶段 4

安全删除

  • 移除旧 token 定义
  • 清理文档
  • 回归浅深两态
