## 结构性 / 长期（按需评估，非缺陷）
- **到期主动推送通知（原 R11）**：真正的系统通知需要后台常驻调度，与「本地离线、不开就不跑」定位冲突；v0.3.0 已用「打开面板即派生提醒（R16）」覆盖核心诉求。若未来接受常驻进程再评估。
- **模型能力与额度 / 生产 Key**：`openrouter/free` 随机分配、约 50 次/天、稳定 function-calling 不保证；需要更稳/更强可切本地 Ollama（免费、不限次、离线）或指定付费/免费模型，`docs/model-providers.md` 已预留 9 家通道。**生产官方 API 真实 Key 仍待所有者配置**（v0.5.0 MANUAL_PENDING：M1/A5）。
- **多设备/多人**：继续不做实时协作；多台电脑看同一份数据可把 `backups/` 或 `data/` 放入 iCloud/坚果云等同步盘，遵守单写者（同步前关闭 dsh），见 `docs/backup-sync.md`。
- **上游升级**：dsh 锁定 v0.2.1-alpha.2；升级前按 `docs/test-cases.md` 全量回归并重核 pi-ai 补丁（ADL-034）。
- **浏览器范围**：仅保证 Chrome（ADL-033），Safari/Firefox 暂不支持。
- **外部 vendored Skills 毕业**：`code-review` 试点 PASS；`grill-me`/`tdd`/`diagnosing-bugs` 各补 1 份试点报告后方可毕业（v0.5.0 NOT_RUN）。
