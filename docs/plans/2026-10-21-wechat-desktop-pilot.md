# 微信 Mac 桌面采集试点部署计划

> 本文件记录本机试点的对象、文件、执行与验证边界，供项目所有者和后续维护者接续。

**Goal:** 部署只读 Mac 微信采集器，按用户指定群名定时采集，在本机保留来源并生成项目动态草稿。

**Architecture:** 采集器是独立本地工具，使用锁定提交的 WeChat-MCP 读取模块。配置空白名单时拒绝采集；辅助功能、屏幕录制或登录未就绪时拒绝动作；采集窗口限量、按时间分隔保留上下文，重复通过连续窗口对齐处理，不声称平台 ID 或全量历史。输出本地动态草稿，不修改 pm-tool 台账。

**Tech Stack:** macOS 15.6.1 arm64、微信 4.1.15 build 270135、Python 3.12.15、WeChat-MCP 0.3.1、PyObjC、macOS Vision、Python 标准库。

## Task 2: 本地采集与诊断入口

- 新建本机 `app/pilot.py`：`doctor`、`configure`、`collect`、`watch`、`report`、`status`。
- 新建本机配置：空群白名单、15 分钟间隔、最多 200 条窗口、每日文件报告、本地整理。
- 采集前检查系统权限/锁屏/微信进程；同名候选拒绝；切群后核对真实标题再读取。
- 一把本机文件锁保证顺序采集；不开放发送工具，不读取密钥或微信数据库。
- 真实消息不输出到终端；JSON 私有目录 0700，文件 0600；日志不含消息正文。
- 原始批次独立保存；连续窗口无法对齐则记录缺口，不靠全文哈希吞掉不同时间重复消息。
- 报告保留采集时间与消息时间分隔文本的区别，未提供准确发出时间时不伪造。
