# pm-tool v0.1.0 发布说明

发布日期：2026-10-10
发布类型：MVP 首个可用版本
维护平台：trae / TRAE

## 版本定位

`v0.1.0` 是 pm-tool 的首个 MVP 发布版。它以独立外挂插件包扩展 DeepSeek Harness，不修改上游源码，在无 API Key 的情况下提供项目、WBS、里程碑、持久化、导出和 Web 工作台。

## 主要功能

- 项目计划：项目新增、查看、编辑、确认删除，含日期与同名防误操作。
- WBS 任务：至少三级任务树、自动编号、编辑、移动、循环保护、确认删除和显式重新编号。
- 里程碑：增删改查、日期排序、达成状态一致性及任务关联保护。
- 数据持久化：Project、Task、Milestone 按记录落为人类可读 JSON，目录 0700、文件 0600。
- 数据导出：单项目 Markdown 报告和整库 JSON 数据包，含覆盖确认和原子写入。
- Web 工作台：dsh 顶级项目管理入口、高密度表格、搜索筛选、状态分组、右侧编辑抽屉，并跟随 dsh 浅色/深色主题。
- 离线命令：完整 `/pm` 命令集，不依赖模型或 API Key。

## 安装与启动

```sh
export NVM_DIR="$HOME/.nvm"
. "$NVM_DIR/nvm.sh"
nvm use 22

cd ~/Projects/dsh-pm/pm-tool/packages/dsh-pm-tool
pnpm install --frozen-lockfile
pnpm run build

cd ~/Projects/dsh-pm/deepseek-harness
pnpm dsh --profile pm --no-open
```

打开终端输出的本机 token URL，点击左侧“项目管理”。首次安装 profile 的完整步骤见 [`../delivery.md`](../delivery.md)。

## 已知限制

- 仅支持单用户、单宿主进程写同一数据目录。
- 当前未实现 JSON 自动导入。
- dsh Web 仅按上游安全策略支持本机 loopback 访问。
- R7-R10 第二梯队能力、R11 到期提醒和生成型 AI 功能未纳入本版本。
- 已验证上游基线为 dsh `v0.2.1-alpha.2`；升级上游前须完整回归。

## 数据与升级

- 业务数据位于 `data/pmtool/`，不随 git/tag 发布。
- 升级或迁移前应停止 dsh 并备份完整 `data/`。
- 本版本数据格式为 `pmtool` per-record version 1。
