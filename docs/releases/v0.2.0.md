# 发布说明 v0.2.0

- 发布日期：2026-10-11
- 平台基线：dsh v0.2.1-alpha.2（上游 `deepseek-harness` 只读，本工具为独立外挂插件 + 专属 profile `pm`）
- 上一里程碑：v0.1.0（R1–R6 离线 MVP）
- LLM 通道：`@deepseek-ai/dsh-llm-pi-ai`，provider `openrouter-free`、模型 `openrouter/free`（OpenRouter 免费自动路由，$0；key 仅放进程环境或 dsh 凭据库，不入库；另在 `docs/model-providers.md` 注释预留 9 家官方/本地通道，当前不启用）

> 一句话：v0.2 在 v0.1.0 离线台账（R1–R6）基础上，补齐风险/会议/汇报/交付物/检索看板（R7–R12），新增三个零成本 AI 生成功能（R13–R15）及其网页入口（A1）、任务安全级联删除（A2）；核心台账始终离线可用，无 API Key 也能完成全部手工管理。

## 一、自 v0.1.0 起新增的功能

### 离线台账与 Web（R7–R12，无 API Key 可用）
- **R7 风险与问题管理**：风险/问题共用台账（概率、影响、应对、负责人、截止、状态），离线命令 + 高密度 Web 表格、筛选、右侧编辑抽屉；有记录的项目禁止删除。
- **R8 会议纪要**：结构化纪要（议题/决议）+ 稳定 ID 行动项，行动项可关联任务/问题/责任人，离线 CRUD 与 Web 表格/抽屉。
- **R9 进度汇报**：自定义日期范围生成固定快照，汇总任务/里程碑/会议摘要与五类异常项；旧快照不被源数据变化改写；支持人工摘要、确认删除与精简 Markdown 导出，Web 可操作。
- **R10 交付物台账**：交付物四态（计划中/制作中/已提交/已验收），状态或版本变化自动留痕（只增 history），离线命令 + Web 台账表格、变更时间线；有交付物的项目禁止删除。
- **R12 检索 / 统计 / 导入 / 总览看板**：
  - `/pm search <关键字> [--type ...]` 跨七类实体只读检索、按类型分组；
  - `/pm stats [项目ID]` 只读统计看板（状态计数、任务完成率、逾期、未关闭风险、交付物四态）；
  - `/pm task import <项目ID> <清单.md> [confirm]` 导入 GitHub 缩进勾选清单还原 WBS（dry-run 预览、`[x]` 记完成）；
  - Web 顶部「总览看板」：跨项目统计卡片、逐项目明细、全局搜索（基于最新 snapshot 派生，不新增宿主路由）。

### AI 生成能力（R13 / R14 / R15，第二里程碑，走免费模型）
- **R13 智能 WBS 拆解**：`/pm task wbs <项目ID> <一句话目标> [confirm]`——调一次模型产出 Markdown 勾选清单草稿，预览确认后复用既有 task-import 链路落盘为任务树；confirm 复用进程内草稿、不再调模型。
- **R14 进度汇报 AI 叙述**：`/pm report narrate <项目ID> [confirm]`——基于确定性采集数字生成本周进展/风险/下周计划叙述，写入既有快照 `executiveSummary`（零 schema 改动），AI 不改台账数字；失败降级为无叙述的确定性快照。
- **R15 会议纪要归纳**：`/pm meeting summarize <项目ID> <速记> [confirm]`——归纳议题/结论/行动项（负责人/截止），防御解析 JSON，confirm 创建 draft 会议并挂行动项；解析失败提示手工录入。
- 统一底座 `core/ai-client.ts`：一次性文本生成（`ctx.llm.prepareCall` + `BlockAssembler`），不依赖 function calling；AI 一律草稿、显式 confirm 才入库；无 Key/限流/超时/空正文均归一为中文提示并优雅降级，核心台账不受影响。

### A1 AI 助手 Web 面板
- 项目工作台顶栏新增「AI 助手」，三模式弹窗（AI 拆解 WBS / 汇报叙述 / 会议纪要），复用与斜杠命令完全相同的 core 草稿→confirm 链路；生成中 loading、按钮禁用防重复调用、中文错误提示、结果先预览显式确认才入库；配色仅用宿主主题 token，适配深浅色与窄屏。
- 修复面板命令误带 `/pm ` 前缀导致返回「不支持的命令」的缺陷（统一为裸子命令），并加防回归断言。

### A2 任务安全级联删除
- 命令：`/pm task delete <id>` 无 confirm 先 dry-run 列出整棵子树；`confirm` 时有子任务仍拒绝并引导；`task delete <id> cascade confirm` 才显式删除该任务及全部后代（旁支不动），保留会议行动项跨表引用保护。
- Web：删除含子任务的任务时弹窗明确「将同时删除 N 个子任务、不可撤销、旁支不受影响」，确认后走 cascade；无子任务维持普通单删。

## 二、兼容性与平台约定
- 浏览器仅承诺/验证 **Google Chrome（现代 evergreen 版本）**（ADL-033），本期不保证 Safari/Firefox。
- 上游 dsh 锁定 v0.2.1-alpha.2（peer 锁 + profile link 装载）；升级上游前须按 `docs/test-cases.md` 跑完整兼容回归，并重新核对/应用 `llm-pi-ai` 相关补丁（ADL-034）。
- 跨平台协作基座（根 `AGENTS.md`、`docs/collaboration.md`、`docs/onboarding-prompt.md`）保证 TRAE/豆包/其他 IDE 克隆即可接续。

## 三、变更与修复
- LLM 超时/中断（免费池偶发 `This operation was aborted`）归一为中文 **MODEL_TIMEOUT** 友好提示并引导重试，不再直抛英文。
- 修复 390px 窄屏视图标签中文逐字断行（标签单行、标签条内部横滚，整页不溢出）。
- 首页对话框 `/pm` 问题经上游源码与真实浏览器双重定位：命令注册本身正确，现象属宿主 composer 行为（输入“/”的斜杠补全截获回车、欢迎页发送后新建会话但主区不自动跳转；外部插件命令无法进入该补全，已记录证据链 ADL-038 / KB-037 / ISS-026）。稳定入口为左侧「项目管理」Web 面板（含 AI 助手）；斜杠命令可用方式：输入完整命令后点蓝色发送按钮，再到侧栏点最新会话查看结果。

## 四、已知限制 / 暂缓项
- `openrouter/free` 由平台随机分配免费模型：纯文本生成可用，稳定 function-calling 不保证；免费档约 50 次/天、20 次/分；推理型模型需给足 max_tokens（建议 ≥400）；偶发限流/超时重试 1–2 次即可恢复，与配置无关。
- **R11 里程碑到期提醒**（依赖常驻调度，与离线优先定位冲突）、**Excel 导入**（依赖 LibreOffice 过重，已可用 Markdown 清单导入替代）、**多人实时协作**（与单用户本地定位冲突）本期暂缓/裁剪（ADL-030/031/032）。
- 核心台账（项目/任务/里程碑/风险/会议/汇报/交付物/检索/统计/导入/导出）始终完全离线可用，不依赖模型与网络。
