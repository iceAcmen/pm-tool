# 发布说明 v0.2.0（草稿 · 待组织者独立验收后打 tag）

> 本文件汇总 pm-tool v0.2 相对上一里程碑的功能与改进。**当前为草稿，未创建/推送 git tag**——tag 由组织者最终独立验收后另行打。

- 日期：2026-10-11
- 平台基线：dsh v0.2.1-alpha.2（上游只读）
- 配置前提：LLM 通道走 `@deepseek-ai/dsh-llm-pi-ai`，provider `openrouter-free`、模型 `openrouter/free`（OpenRouter 免费自动路由，key 仅放进程环境/凭据库、不入库）。

## 新增功能

### 生成型能力（R13 / R14 / R15，第二里程碑）
- **R13 智能 WBS 拆解**：`/pm task wbs <项目ID> <一句话目标>` 调一次模型产出 Markdown 勾选清单草稿，预览确认后复用既有 task-import 链路落盘；`... confirm` 复用草稿不再调模型。
- **R14 进度汇报 AI 叙述**：`/pm report narrate <项目ID>` 基于确定性数据（任务/里程碑进度）生成本周进展/风险/下周计划叙述，数字以确定性快照为准、AI 不改台账；`... confirm` 生成带 executiveSummary 的进度快照。
- **R15 会议纪要归纳**：`/pm meeting summarize <项目ID> <速记>` 归纳议题/结论/行动项（负责人/截止），`... confirm` 创建 draft 会议并挂行动项。
- 统一底座 `core/ai-client.ts`：一次性文本生成、不依赖 function calling、草稿 confirm 才落盘、失败归一为中文 AiDraftError 优雅降级（含超时/MODEL_TIMEOUT）。

### A1 AI 助手 Web 面板
- 项目工作台顶栏新增「AI 助手」按钮，三模式弹窗，复用同一 core 草稿→confirm；生成中 loading、防重复点击、中文错误、结果先预览显式确认才入库。

### A2 任务安全级联删除
- `/pm task delete <id>` 无 confirm 先 dry-run 列出整棵子树；`confirm` 有子任务仍拒绝并引导；`<id> cascade confirm` 才显式删除整棵子树（旁支不动），保留会议行动项跨表引用保护。

## 变更 / 修复
- LLM 超时/中断（免费池偶发 `This operation was aborted`）归一为中文 MODEL_TIMEOUT 提示，不再直抛英文。
- 首页 `/pm` 问题定位为宿主 composer 行为（斜杠补全截获 Enter、发送后主区不自动跳转）；命令注册本身正确，以 Web 面板为稳定入口、并提供点发送按钮的用法说明。

## 已知限制
- `openrouter/free` 随机分配免费模型：纯文本生成可用、稳定 function-calling 不保证；约 50 次/天；推理型模型需给足 max_tokens（建议 ≥400）；偶发超时重试即恢复。
- 核心台账始终离线可用，不依赖模型。
- 删根任务须叶子→根逐层删，或用显式 `cascade confirm`（A2）。

## 验证
