# 发布说明 v0.3.0

- 发布日期：2026-10-11
- 平台基线：dsh v0.2.1-alpha.2（上游 `deepseek-harness` 只读；独立外挂插件 + 专属 profile `pm`）
- 上一版本：v0.2.0（R1–R15 + AI 助手 Web + 任务级联删除）
- LLM 通道：OpenRouter 免费自动路由 `openrouter/free`（$0，key 仅存进程环境/凭据库，不入库；另有 9 家官方/本地通道在 `docs/model-providers.md` 注释预留）

## 本版本主题：离线增强（R16/R17/R18）+ 第二档体验增强（T2）

### 第一档 · 离线增强
- **R16 临期/逾期提醒**：`/pm due [天数] [项目ID?]`（默认全部项目、未来 7 天）；Web 面板打开即在顶部显示提醒条，逾期红、临期黄，自动排除已完成任务与已达成里程碑。纯读时从当前数据派生，**不做后台常驻调度**（ADL-039）。
- **R17 会议行动项转任务**：`/pm meeting action promote <会议ID> <行动项ID> [confirm]`，在会议所属项目下创建任务（标题/负责人/截止日自动带入）并幂等回写 `action.taskId`；Web 会议详情抽屉内每条行动项有「转任务」按钮，已转换显示「已转 t-xxxx」并禁用（ADL-040）。
- **R18 数据备份/恢复**：`/pm backup [目录?]` / `/pm restore <备份文件> confirm`；备份仅含 pmtool 七类实体（项目/任务/里程碑/风险问题/会议/汇报/交付物），**不含宿主会话数据与密钥**；恢复为两步确认、恢复前自动生成安全快照；Web 面板提供一键备份；新增 `docs/backup-sync.md` 说明备份与 iCloud/坚果云多设备同步的单写者注意事项（ADL-041）。

### 第二档 · 体验增强
- **T2-A AI 助手体验**：内置「官网改版 / App 版本迭代 / 活动筹备」等 WBS 目标模板一键填入；localStorage 记住上次模式与目标；**WBS 草稿预览改为可编辑 Markdown 清单**（可改字、增删行、勾选），确认时按编辑后文本落盘、不再调用模型（命令 `task wbs --raw` + `task importmd`）。
- **T2-B 列表效率**：任务行复选框多选 + 批量工具条（批量标为完成 / 批量删除，删除严格复用 A2 级联二次确认）；排序下拉（截止日期/优先级/进度）；各视图空数据中文提示与快捷入口。
- **T2-C CSV + XLSX 导入**：`/pm task import <项目ID> <文件.csv|.xlsx> [confirm]`，dry-run 预览→confirm 复用任务树落盘；CSV 为零依赖纯 JS 解析，XLSX 采用 SheetJS `xlsx@0.18.5`（Apache-2.0，仅 node/命令侧动态 import，不进浏览器 bundle）；约定表头「层级/标题/负责人/优先级/开始/截止/进度」，坏文件/坏表头中文报错（ADL-030 由“裁剪”改写为“纯 JS 离线实现”，ADL-043）。
- **T2-D 导出便利**：面板「导出 JSON」经浏览器 Blob 直接下载；「导出 Markdown」运行导出命令并提示文件绝对路径。
- **本期裁剪（ADL-042）**：R14/R15 叙述与纪要预览的可编辑落盘、批量改负责人的高级 Web 表单（core/命令行已支持）、键盘快捷键——价值较低，列入 `docs/optimization-backlog.md`。

### 可访问性与打磨（真实 Chrome 回归后修复）
- 会议列表整行可点击打开详情抽屉，行末新增「详情」按钮，hover 高亮——确保 R17「转任务」入口清晰可达。
- 导出 JSON 文件名加时间戳 `pmtool-snapshot-YYYYMMDD-HHmm.json`（不再互相覆盖）；导出/备份成功改为顶部 Notice 提示（含条目数/路径）；备份、导出 Markdown、导出 JSON 按钮与会议行动项计数补 tooltip；第二档新控件补稳定 class 选择器以支持自动化回归。

## 已知限制
- `openrouter/free` 随机分配免费模型、约 50 次/天，偶发限流/超时（已归一为中文 MODEL_TIMEOUT，重试即恢复）；核心台账始终离线可用。
- 首页对话框斜杠补全不显示第三方插件命令、回车被补全截获属宿主行为（ADL-038/KB-037/ISS-026）；稳定入口为左侧「项目管理」面板。
- 浏览器仅保证 Chrome；备份目录 `backups/` 已 gitignore，恢复为两步操作并自动安全快照。
