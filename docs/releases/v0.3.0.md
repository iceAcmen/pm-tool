# v0.3.0 发布说明（草稿 · 待组织者独立真实 Chrome 验收后打 tag）

> 状态：**草稿**。代码已提交并推送 origin/main；真实浏览器端到端验收与打 tag 由组织者独立完成，本仓库**不创建/推送 git tag**。

## 本版本主题：离线增强（R16/R17/R18）+ 第二档体验增强（T2）

### 第一档 · 离线增强
- **R16 临期/逾期提醒**：`/pm due [天数] [项目ID?]`（默认全部项目 7 天）；Web 面板打开即显示提醒条，逾期红、临期黄。纯读时派生，不做常驻调度（ADL-039）。
- **R17 会议行动项转任务**：`/pm meeting action promote <mtg> <ai> [confirm]`，幂等回写 `action.taskId`；Web 行动项加「转任务」按钮，已转禁用（ADL-040）。
- **R18 数据备份/恢复**：`/pm backup [目录?]` / `/pm restore <文件> confirm`，覆盖 pmtool 七类实体、不含宿主会话与密钥，恢复前自动安全快照；Web 一键备份按钮；`docs/backup-sync.md` 给出云同步单写者指引（ADL-041）。

### 第二档 · 体验增强（已补齐）
- **T2-A AI 助手体验**：内置 WBS 模板一键填入；localStorage 记忆上次模式/目标；**WBS 预览改为可编辑 Markdown 清单**，确认入库按编辑后文本落盘（不调模型，`task wbs --raw` + `task importmd`）。
- **T2-B 列表效率**：任务行复选框多选 + 批量工具条（标为完成 / 批量删除，删除复用 A2 级联二次确认）；排序下拉（截止/优先级/进度）；空状态中文提示。
- **T2-C CSV + XLSX 导入**：`/pm task import <项目ID> <文件.csv|.xlsx> [confirm]`；CSV 纯 JS 自解析，XLSX 用 SheetJS `0.18.5`（Apache-2.0，动态 import 不进 client bundle）；表头「层级/标题/负责人/优先级/开始/截止/进度」。
- **T2-D 导出便利**：面板「导出 JSON」经浏览器 Blob 直接下载；「导出 Markdown」运行命令并弹窗路径。
- **裁剪项（见 ADL-042/043）**：narrate/summarize 可编辑落盘、批量改负责人高级表单、快捷键。
