## 一、本版本主题：v0.6.0 UX 人工反馈补丁 + 后端数据安全

> 内容口径：用户在 v0.6.0 正式运行态人工验收反馈的体验类缺陷（`docs/testing/v060-manual-feedback-regression.md`，R1-01…R8-01）与对应修复；独立测试专家已最终签发 PASS。

### UX 反馈补丁（R1–R8 体验项，14/14 全 PASS）
- **备份确认 / 路径恢复（R1-01、R1-02）**：一键备份走 confirm 弹窗（将备份的七类实体、取消零写）；成功 Notice 含生成文件名 + 可读路径；恢复入口可见、file picker 只接受 pmtool backup JSON、选择后先演练预览（将替换的七类实体/文件名）再确认落库。
- **长提示可滚动（R2-01）**：级联删除等长确认 Notice 改为 max-height + overflow:auto，关键数量不被省略号截断。
- **键盘导航（R3-01/R3-02/R3-03）**：j/k 逐行移动焦点并有持久 active 高亮；Space 作用于当前焦点行而非恒为第 1 行；输入框/抽屉聚焦时 j/k/Space 门控不劫持。
- **390px 顶栏（R4-01）**：窄屏下顶栏项目名可读、按钮文字/图标尺寸一致、不横向溢出/裁切。
- **移动 / promote 入口（R5-01、R5-02）**：任务行提供可见文字「移动到…」入口、父级树选器正确排除自身+后代；会议行动项有可见「转为任务」按钮，确认后生成任务并回写 `action.taskId`。
- **甘特可读性（R6-01、R6-02）**：日期 tick 抽稀不重叠、条带对齐、今日线清晰；无开始/截止任务有 unplanned 占位提示，点条打开任务抽屉编辑日期。
- **副驾 lane / loading（R7-01、R7-02）**：请求期间显 loading/思考中态（禁用重复提交、读屏 busy）；poc/prod 模型车道标签在副驾区可见可点、`aria-selected` 正确。
- **前置依赖紧凑树（R8-01）**：WBS 父子缩进、`code/title/status` 清晰（done 着色/灰）、checkbox↔文字 gap 4–8px、整行 label 可点、长列表 max-height 滚动。

### 后端数据安全加固
- **恢复队列化**：备份恢复不再半写滞留，按队列顺序执行、失败自动回滚。
- **批删全预检**：批量删除先全量预检（连带删除范围/数量）再统一确认，任一项不过则整批不落库。
- **exports guard**：导出产物走 guard 清单，运行前后 sha256+mtime diff 零污染。
- **模型状态往返**：`/pm model mode` poc/prod 状态在进程往返、重启读回一致。
