## 一、本版本主题：甘特排期视图信息增强（信息可读性 · 零 schema）

> 内容口径：ADL-045 / ADL-047 甘特信息增强验收矩阵最终签（`docs/testing/gantt-information-acceptance.md`）；被测对象 = `src/core/gantt.ts` 纯函数层 + `src/client/panel.tsx` 的 `<GanttView>` 渲染层。

### 根因修复：`--pm-accent` 透明
- **`--pm-accent` 变量缺失根因修复**：甘特条底色 `color-mix(in srgb, var(--pm-accent) …)` 此前因 `--pm-accent` **从未在调色板定义**而退化为透明，条体肉眼几乎不可见。根因修复 = 在调色板正式定义 `--pm-accent: var(--dsw-alias-state-business-primary)`；此后甘特条底色轨道 / 进度实心层 / 父条虚线 / `:focus-visible` 描边全部走该宿主语义变量，**不硬编码 hex**。

### 信息直显
- **起止日期直显**：任务条上 / 标签列直接渲染 `MM-DD ~ MM-DD`（`labelDates`）；单日窄条文字外置为右侧 `sideLabel`，**不只藏在 hover tooltip**。
- **0 / 部分 / 100 进度可视化**：条内进度实心层按 `progress/100` 比例填充（0 空 / 半填 / 满填）；`status==='done'` 或 `progress>=100` 视为完成态；**纯渲染、不写库**。

### 依赖与父子派生（全部只读）
- **predecessorIds 只读 SVG 箭头**：依赖线 / 箭头全部由唯一真源 `predecessorIds` 派生成 SVG `path`（`pointer-events:none` 不可交互、不可"画线即改依赖"）；自指 / 成环 / 悬空 / 缺日期诚实 `skipped` 降级、不递归死循环、不写库；甘特**不维护第二份依赖副本**。
- **父子 effectiveRange 只读派生**：父条范围 = `min(子 start) ~ max(子 due)` 的只读派生（虚线派生条），**不回写父任务日期**；无排期子 → 不画父条。

### 健壮性与可及性
- **ARIA / 本地 today / 里程碑防 NaN**：任务条 `tabIndex=0` / `role=button` / `aria-label` 含「任务名 · 起止 · 进度 · 前置」，依赖 SVG `aria-label` + 每边 `<title>`；今日线由 `localTodayIso()` 注入、轴外钳制不溢出画布；里程碑缺 `targetDate` 纯函数层返回 `null` 不画、**不 NaN**（手写 `targetDate:null` 的恶意记录由宿主就绪守卫整体拒绝打开、不自动修复 / 不隔离 / 不画错条）。

### 拖拽改期语义
- **拖拽只 start/due、不自动后继**：整条**平移**保持原时长，落库 payload 白名单**仅含 `startDate` / `dueDate` 两键**；不因此改动 `progress` / `predecessorIds` / `status` / `assignee`；依赖线随坐标重算，但**不把后续任务自动顺延**。
