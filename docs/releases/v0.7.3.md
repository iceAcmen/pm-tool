## 一、本版本主题：甘特拖拽手感与成功提示热修（零 schema）

> 内容口径：用户在 v0.7.2（`310c768`）实测反馈——拖拽成功后弹出**全字段深色大卡 Notice**（任务ID/WBS/项目/父任务/标题/说明/负责人/状态/优先级/起止/进度/里程碑 13 行 dump），盖住甘特工作台。本补丁就地修复拖拽手感与成功提示，不改甘特信息增强既有能力。

### 根因修复：`nowrap + hint` 致时间轴滚动区宽 0
- **`.pm-gantt` 加 `flex-wrap: wrap`（GI-WEB-16 首行宽度契约根因修复）**：无 wrap 时，`hint(flex-basis:100%)` 与左侧 `labels(230px)` / 右侧 `scroll(flex:1,min-width:0)` 挤在同一 flex 行互相竞争，`scroll` 被 shrink 到 **0（画布宽消失）**。wrap 后 hint 独占下一行，首行恒为 `labels(固定230px) + scroll(flex:1,min-width:0)`，hint 出现/消失**不改变首行宽度**；拖前实测 `.pm-gantt-scroll` clientWidth=768（scrollWidth=992，可横滚）。

### 拖后 DOM 保留 + 即时更新（无需 F5）
- **拖拽走 `run(...,{quiet:true})`、单 refresh**：松手即落盘 + `refresh()` 一次就地重渲染，被拖条起止日期立即=拖拽后新值，**无需 F5/切 tab**；移除旧 `onSaved()` 二次刷新，不跳回首条、不滚顶、不整树重挂载；拖后实测 bars=9、svg=1、path=1、arrow=1 均在（clientWidth=768 不塌）。

### quiet 成功：无全字段大 Notice，改轻量 aria-live
- **成功不再弹全字段深色大 Notice**：`run` 新增 `options.quiet`——成功只 `refresh()`、**不 `setMessage(response)`**（不再 dump 13 行字段盖住工作台）。
- **轻量 inline `role=status`**：条下状态行渲染 `已更新：2026-10-18 ~ 2026-10-21`（`aria-live="polite"`），**约 3s（3000ms）自清除**；确认后无需关闭任何卡片即可继续横滚/再拖/切 tab，甘特始终可交互。

### saving 防连拖 + 失败回落 + 不吞错
- **`saving` inflight 锁（GI-WEB-19）**：保存中同任务/甘特拖拽 `onPointerDownBar` 直接 `return` 禁拖，`finally` 无论成败都解锁（防漏）；实测紧接两次拖拽只落 ≈1 步（shift≈3 而非 6）、任务文件数恒 10 无 ghost。
- **失败回落无 ghost**：松手先 `setPreview(null)`，且条体从未本地改动——快照未 `refresh` 自然回落拖前坐标；实测故障注入后 t-0005 geom 576px/64px 前后一致。
- **quiet 不吞错**：`run` 的 `catch` 仍 `setMessage(error)`——全局错误 Notice（`任务操作失败，未返回成功结果…`）**不被 quiet 吞掉**；同时内联 `更新失败，请重试`（6000ms）。故障四断言：内联错误可见、全局错误红框可见、条坐标回落、服务端该任务 start/due/progress 逐字节零写。

### 单 refresh / timer cleanup / payload 白名单（零 schema）
- **unmount 清定时器**：`statusTimer` 在卸载时 `clearTimeout`，快速连续拖/切视图不得有陈旧定时器回写旧状态。
- **payload 白名单 / 零 schema**：拖拽落库仍仅 `startDate`/`dueDate` 两键；重启 `--reopen` 读回 progress=40、predecessorIds=[t-0004]、assignee 逐字节未动；**不新增表/列、不改 `taskRecordSchema`、不升 domain、不动 `core/storage.ts`**。
