## 判定图例（与 ADL-045 严格一致）

- **PASS**：被测行为经真实执行/代码证据验证满足验收；**离线纯函数/HTTP200 不算网页实测 PASS**。
- **FAIL**：已实测且与验收不符；阻塞开发。
- **BLOCKED**：受能力/环境限制无法实测，诚实标注原因；**不等于通过**，阻塞继续开发。
- **NOT_RUN**：计划内但本轮未执行（排入后续）。

> 硬规则：`FAIL / BLOCKED / NOT_RUN` 一律 ≠ 通过；GUI 实测是硬门槛；严重度只排修复先后，不自动豁免；任何新提交使受影响历史结论过期，须重测后方可再引用。
