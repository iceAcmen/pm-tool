## P0 用例（route / 输入 / 预期存储 / 回滚）

### B2-P0-C1 新建：资料/进展只进本地草稿，保存前零写
- **route/input**：tasks → 新建任务抽屉（`task` 未定义）；在（若 front 实现新建草稿区）输入 link URL/标题/备注、选交付物、填进展作者/正文/日期。
- **预期存储**：未点主保存前**不发任何写命令**（无 task、无孤儿 attachment/progressLog）；输入仅存本地 pending draft。
- **回滚/取消**：Cancel / ESC / scrim / 关闭按钮，且未点主保存 → 零写（项目下无新任务、无残留资料/进展）；dirty 未保存弹放弃确认（沿用 O4 confirmDanger）。
- **主保存**：`task add {basic payload}` 创建任务成功；若本地 pending arrays 需落库，显式经专用动作追加（成功/错误各自可见），不得在 `task add` payload 里塞 attachments/progressLog（schema 拒收）。
- **禁止**：新建未保存就即时写资料/进展；把本地草稿静默丢弃却不提示。

### B2-P0-E1 编辑：basic+同次校验，非法全零写，不得半写
- **route/input**：打开已有任务抽屉；改 basic（title/description/assignee/status/priority/startDate/dueDate/progress/milestone/predecessor/repoUrl/branch/effort/evidence/manualProgress）。
- **预期存储**：主保存 `task update <id> {basic payload}` 单条；前端 `validateTaskForm` 先行，**任一非法（title 空、截止早于开始、progress 越界、repo 非法、必填缺失）→ 全部零写**，保留全部输入、首错聚焦，不允许部分字段先落库。
- **回滚**：校验失败不关抽屉、不清输入；命令返回 error（run=false）不关抽屉、保输入、就近/全局显错。
- **原子口径**：basic 区是一次主保存；arrays 不走这条 `task update`，不得借主保存夹带数组。

### B2-P0-E2 资料/进展 quick-manage = 独立即时动作，不得伪装主原子保存
- **route/input**：编辑抽屉资料区/进展日志区的单项操作：加链接、关联交付物、移除资料；追加进展、内联编辑保存修订、软删、恢复、历史回看。
- **预期**：每项走各自专用命令（b2-commands 构造，精确参数 QA 已探针核验）；单项成功即提交、刷新快照，**这是独立即时写，不是主保存原子事务**，UI 不得把它标成「随主保存一并提交」。
- **失败**：前置校验失败不调 run、保输入；命令 error 不关抽屉、保输入。
- **软删**：进展软删保留全 revision，「已删除」区可展开 restore，不物理隐藏。

### B2-P0-E3 混合态：已提交数组不被 basic 取消回滚
- **场景**：编辑中先成功执行了一次资料/进展即时动作（已落库），再改 basic 未保存即取消。
- **预期**：取消只丢弃未保存的 basic 草稿，**不回滚已成功提交的数组事实**；dirty 守卫仅覆盖未保存 basic，不得对已 committed 数组做撤销。
