# 视觉证据采集受限说明与采证清单（2026-10-17）

## 1. 结论

当前执行通道无法采集真实浏览器视觉证据：本层既不能驱动桌面界面，也无法在浏览器内产出可用的页面截图。因此 **G3 真实 GUI 目视门在本层判 BLOCKED**，不填 PASS，也不以静态检查或结构核对代替目视。

> **2026-10-17 口径更正**：隔离实例先前的认证提示是**导航未带该实例 URL token，非实例不可达、非主端无 GUI**；用户接管超时。认证分支停止（不填 token、不换端口/驱动、不直连绕认证）。主端将带链接导航重建隔离实例采证；带链接即可进入。本测试层自身仍不驱动浏览器，证据由具备通道的一方采集后交本专家独立审证。

可独立离线完成的部分（构建回归、Token 静态门、非回归静态核对、AI 离线治理闭环）不受影响，照常执行；待具备真实浏览器采集条件后，由具备通道的一方按 §4 清单采证，测试专家据原始证据独立审证。

## 2. 受限范围

- 无法完成：浅/深主题 × 1440 / 约768 / 390 的真实页面目视走查、页面截图、物理指针手势（如甘特拖拽改期/拖工期）、读屏与 200% 缩放实测。
- 不做绕过：不使用自动化脚本替代人眼目视，不把结构核对、计算色值或截图数量当作视觉通过。
- 不臆断：未实际打开的页面状态不做推断；受环境限制无法实测的项如实标 BLOCKED/MANUAL_PENDING。

## 3. 本层仍可独立覆盖（离线）

- G1：构建、单元测试（含覆盖率门）、全量隔离校验、确定性端到端（隔离存储、非生产环境、不出网、不调模型）。
- G2：迁移映射全覆盖、旧别名同值可解析、零未定义变量、宿主别名优先、对比度计算实测、零暖黄/新品牌色/渐变推广、S4 紫色不定义不启用（未来另定）。
- G4：已 PASS 项与已实现界面的静态/非回归核对。
- P2-6 离线治理闭环：草稿确认前零写、确认落库、撤销回滚、拒绝/失败路径，用确定性用例验证，不调用收费模型。
