### O1 结论
**仍在外（未修复），需 owner 裁决。** 复测 `rect.x=1486.66 / right=1593.70 > innerWidth=1440`，与基线 `x≈1486` 一致；成因是工具条 `overflowX=visible` 不裁剪 + 密度占位件占宽 326px 把主 CTA 挤出右缘。圆角 8px 与中性填充均正常（W-DEF-001 不回潮），本项纯属放置/布局，测试通道不自行改代码，裁决材料如上。

## O2 链接实例补证（新建 1 条含 URL 的任务记录）

### 补证前状态（基线）
- 5 个种子项目无「来自会议」链接、无 markdown 行内链接，全站无 `<a>`；W-DEF-004 以 token 解析 + 引用元素同色实测关单（token 层 PASS），**链接实例视觉待有链接实例环境补证**。

### 动作（授权写：仅新建 1 条记录，不删改既有）
1. 新建任务抽屉：标题「O2 链接补证任务」；**仓库地址 repoUrl = `https://example.com`**；证据链接 evidenceUrl = `https://example.com/evidence`；提交「添加任务」。
2. 保存后重开该任务编辑抽屉（铅笔「编辑 O2 链接补证任务」），取 `.pm-repo-row[data-repo-link] a` 视觉与 DOM。
3. 键盘取证：Shift+Tab 反向可达；聚焦后 Enter 触发 `target=_blank` 新标签；记录 outerHTML。

### 结果证据

**计数**：补证前侧栏「全部任务5」→ 保存后「全部任务6」（仅 +1，零污染）。

**记录类型如实说明**：任务表单的「证据链接」字段仅为文本输入（不渲染 anchor）；真正渲染**真 anchor** 的是「仓库地址 repoUrl」字段（任务编辑抽屉顶部 `.pm-repo-row`）。故本条记录：repoUrl 提供可点击 anchor，evidenceUrl 仅作存储旁证。

**链接视觉**（`O2-link-任务.png`；聚焦特写 `_o2-anchor-focused.png`）：
- GitBranch 图标 + 链接文本 `https://example.com`，**下划线（text-decoration: underline）**、`cursor: pointer`，可辨可点。
- 颜色 `rgb(15,17,21)`（color: inherit 继承正文，未走 `--pm-link` token 着色）——属本实例现状，如实记录，不影响 W-DEF-004 token 层关单结论。

**DOM 取证（outerHTML 摘录）**：
```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer">https://example.com</a>
```
- 真 anchor：`tag=a`，`href=https://example.com`（resolved `https://example.com/`），`target=_blank`，`rel=noopener noreferrer`，`tabIndex=0`，`visible=true`（rect x=931 / right=1046 / y=101 / 115×17）。
- **键盘可达**：从首字段 title 按 **Shift+Tab ×1** 即落焦 anchor（`shiftTab.reached=true`）。
- **Enter 激活**：聚焦 anchor 后按 Enter → 新标签打开 `https://example.com/`（`enter.activated=true, openedUrls=["https://example.com/"]`）；真实鼠标点击同样打开新标签（旁证）。
- 如实旁注：从 title 正向 Tab ×30 步不经过该 anchor（anchor 在 DOM 中位于首字段之前，需 Shift+Tab 反向到达；正向环绕在本抽屉焦点流内未回卷）。

### O2 结论
**PASS（实例层补证成立）**：存在真 `<a href target=_blank rel=noopener>` anchor，下划线 + pointer 可辨，Shift+Tab 可达、Enter 触发新标签激活。证据链接字段本身不渲染 anchor（已如实说明）；repo-row anchor 颜色继承正文、未用 link token 着色，列为现状旁注，不回滚 W-DEF-004 token 层关单。
