## 6. 判定图例与证据规范（ADL-045）

- **PASS**：真实执行/实测满足；离线纯函数/HTTP200/截图数量**不算**网页目视 PASS。
- **FAIL**：实测与验收不符，阻塞。**BLOCKED**：环境/能力受限无法实测，诚实标因，≠通过。**NOT_RUN**：计划内未执行。**MANUAL_PENDING**：确实需用户本人参与的项。
- 每条结论绑定提交 SHA + 证据（日志/断言行/代码行/截图，谁产生、何时）；新提交使历史结论过期 → 重测后才可引用。
- 缺陷按 `defect-format.md` 全字段（编号/标题/严重度/被测提交/现象/预期/证据/根因初判/影响/复现/状态/指派）；严重度只排先后不自动豁免，WONTFIX 须所有者特批。
- 最终报告与浅深截图落 `docs/testing/`（绝对路径回报），报告副本存测试专家 artifacts；本地文件走 verifier-hub 校验并明确结果，视觉文件须截图检查。
