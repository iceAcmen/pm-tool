## 执行与最小合同

1. 只读 AGENTS/collaboration、A3/A4、bridge/panel/index，记录源码指纹与证据层。
2. 先写本计划，再新增独立 Node 探针。TypeScript仅内存去类型，不写产物、不跑产品build。合成句柄只用 N1/N2 标记，fetch替身只在内存记录，不发HTTP。
3. 保存修复前红例：同实例 N1→N2必须分别调用fetch；旧N1完成不得清N2；跨token在途不能借旧成功宣称N2已回告。
4. 正控制：首次成功、同token并发去重、失败保hash重试、无token不发、新实例N2成功、同nonce不同port不能被旧done吞掉。
5. 独立DOM如执行，必须全新headless profile、自有tmp、无HTTP服务器、拒绝全部网络；不是Main tab、宿主或认证GUI。缺依赖不install，保纯函数与静态边界。
6. 输出诊断报告、证据索引、命令/退出码及最小修复测试合同。测试以“正确行为”写断言，红例保留，不把“确认bug的脚本exit0”称产品PASS。

## 停止条件

- 原证含真实凭据或需要读禁止根才能继续：停止该原证审查，其他独立实验继续。
- 生产 bridge/panel 指纹变化：记录漂移并重认领受影响实验，不沿旧报告扩大结论。
- 给出可复现源码缺陷和有限合同后交开发修复；本专家不实现、不自验收。
