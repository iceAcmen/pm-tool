### R3-DEF-004（P0）网页备份内容的外层参数编码与内层 JSON 混淆（OPEN / FAIL）

- 旧手写夹具确实过期（另记 R3-TDEF-001），但使用产品自身生成的合法 `pm-tool-backup/formatVersion=1` 备份仍被演练拒绝为“备份文件不是有效 JSON 对象”。
- 页面通过 `JSON.stringify(content)` 把文件文本编码为命令参数，因此 handler 收到的是“JSON 字符串字面量”；必须先解外层参数，得到原始备份 JSON 文本，再解析并校验备份对象。
- 现实现把外层命令参数和内层备份 JSON 混用，导致合法文件也被当成字符串而非对象。
- 预期：统一 decoder 同时支持网页字符串参数与直接 raw JSON；dry-run、confirm 使用同一解包语义，并以真实网页编码方式建立回归测试。
