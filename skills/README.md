# skills/ 目录说明

> 本目录用于沉淀可复用的 **Skill 定义**（项目知识与操作流程的标准化封装），目标是在新环境中无需口头交接即可复用；给维护者与迁移的软件使用。阶段 1 仅建立目录与约定，**具体 Skill 从阶段 3 起随功能开发补充**。

## 约定

- 每个 Skill 一个独立子目录或一个 Markdown 文件，使用通用 Markdown 描述：用途、触发场景、输入、步骤、所需命令/依赖、输出。
- 命名清晰、与 `docs/requirements.md` 的功能模块编号对应（如 `R2-wbs-task-breakdown`）。
- Skill 中引用的命令必须可复制，并注明运行环境（macOS + nvm Node 22 + pnpm）。
- 不依赖任何特定软件的私有标记；如产生私有格式文件，需同时提供 Markdown 说明。

## 规划中的 Skill（阶段 3 细化）

- 项目初始化 Skill：新建项目并生成标准计划骨架。
- WBS 任务拆解 Skill：将目标逐层拆解为可执行任务。
- 里程碑/风险检查 Skill：扫描临近里程碑与未关闭风险。
- 进度周报生成 Skill：汇总任务与里程碑数据生成报告。
